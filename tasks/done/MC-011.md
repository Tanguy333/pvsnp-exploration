## 1. LEMME (léger ⟹ singleton, TOUS les cœurs)

Soit p un séparateur d'un cœur à deux points u, v (comparable : u =
0-point ; incomparable : u = A, v = B) et l ∈ O un extérieur **léger**
(ω_l = 1, où ω_l est le poids des monômes d'O-part exactement {l}).
**Alors l'unité de ω_l est le singleton : a_{{l}} = 1.**

*Preuve.* Les points u∪{l} et v∪{l} sont des zéros (ils contiennent l,
donc ne sont ni u ni v). De p(u∪{l}) = p(u) + Σ{a_S : l ∈ S ⊆ u∪{l}} ≠
p(u) suit que la famille F_u := {S : l ∈ S ⊆ u∪{l}} porte un poids ≥ 1 ;
de même F_v ≥ 1. Si a_{{l}} = 0 : tout membre de F_u autre que {l}
rencontre u, tout membre de F_v autre que {l} rencontre v ; pour le
comparable, u = ∅ rend F_u = {{l}} de poids 0 — contradiction immédiate ;
pour l'incomparable, F_u∖{{l}} et F_v∖{{l}} sont disjointes (leurs
membres rencontrent A resp. B, disjoints) et portent chacune ≥ 1, d'où
ω_l ≥ 2 — contradiction avec la légèreté. Donc a_{{l}} ≥ 1, et ω_l = 1
force a_{{l}} = 1 exactement, sans autre monôme d'O-part {l}. ∎
*(Généralise le lemme réparateur de VER-MC-1 (cas (1,1)) et le fait F1
de MC-010 (cas comparable, où il redécoule de p({l}) ≠ p(∅) = 0).)*

## 2. THÉORÈME (loi comparable complète) — F(0, b, 0, o) = b + 2o pour TOUT o, b ≥ 2

Majorant : la construction comparable (MC-009 §4). Minorant, par
récurrence sur o. **Base o = 0** : W ≥ s₁ ≥ b (F1 de MC-010 : tout
singleton est un zéro de valeur a_i ≠ p(∅) = 0). **Pas o ≥ 1** : soit p
un séparateur, W son poids ; notons, pour l ∈ O, μ_l le poids des monômes
multi-extérieurs contenant l. Trichotomie :

1. **∃ l lourd (ω_l ≥ 2).** La restriction x_l := 0 supprime exactement
   les monômes contenant l (poids ω_l + μ_l) et donne un séparateur du
   cœur (b, o−1) — les deux uns vivent dans la tranche, la disjonction se
   restreint. Par récurrence :
   W − ω_l − μ_l ≥ b + 2(o−1) ⟹ W ≥ b + 2o − 2 + ω_l + μ_l ≥ b + 2o.
2. **∃ l léger avec μ_l ≥ 1.** Même restriction : perte
   ω_l + μ_l = 1 + μ_l ≥ 2 ⟹ W ≥ b + 2o.
3. **Tous les l légers et μ_l = 0 pour tout l.** Alors μ = 0 (tout monôme
   multi-extérieur contient un l et pèserait dans son μ_l), et chaque
   léger porte son singleton (Lemme §1). Pour tout L ⊆ O et X ⊆ B :
   p(X∪L) = p(X) + |L| — seuls les singletons de L s'activent en plus.
   En X = X_j := B∖{j} (zéros) : D_j := P − p(X_j) ∉ {1, …, o}, et
   D_j ≥ 1 (F2), donc D_j ≥ o + 1 pour tout j. La convexité (MC-010 :
   Σ_j D_j = Σ_{S⊆B} |S| a_S ≤ s₁ + b(W_B − s₁), s₁ ≥ b) donne
   W_B ≥ b + o. D'où W = W_B + Σ_l ω_l + μ = W_B + o ≥ b + 2o. ∎

**Corollaire (avec MC-009).** F(0, b, m, o) = b + 2o + [m ≥ 1] est un
THÉORÈME pour tous b ≥ 2, m, o — le plafond o ≤ 7 de MC-010 est levé,
l'inégalité de recouvrement et sa zone d'échec (8,5) sortent du chemin
critique (le théorème B de MC-010 est supplanté).

## 3. THÉORÈME (loi (1,1) complète) — F(1, 1, 0, o) = 2 + 2o pour TOUT o

Majorant : la construction (1,1) (VER-MC-1, intégrée à MC-009 §4).
Minorant, même récurrence. Base o = 0 : W ≥ p₁ + p₂ ≥ 2 (les uns valent
≠ 0 = p(∅), zéro). Pas : branches 1 et 2 identiques (perte ≥ 2, ones dans
la tranche x_l = 0). Branche 3 (tous légers, μ = 0) : chaque léger porte
son singleton (Lemme §1) ; pour L ⊆ O non vide, p(L) = |L| est une valeur
de zéro, donc p₁, p₂ ∉ {1, …, o} et p₁, p₂ ≥ 1 ⟹ p₁, p₂ ≥ o + 1 ⟹
W ≥ p₁ + p₂ + Σω_l ≥ 2(o+1) + o ≥ 2 + 2o. ∎

## 4. Ce que ça change — et ce qui reste

- **Sandwich fermé sans condition** sur les deux familles : comparable
  (∀ b ≥ 2, m, o) et (1,1) (∀ o) — des théorèmes hors de portée de tout
  solveur, obtenus par une induction de quatre lignes par branche.
- **Le lemme de normalisation (μ = 0) n'est plus nécessaire** — il reste
  vrai sur tous les cas testés (mode `normalisation` du script :
  min{W : μ = 0} = W partout) et consigné comme observation.
- **Reste ouvert, nommé** : la base incomparable o = 0 — F(a, b, 0, 0) ≥
  2(a+b) − max(b, 2, a+b−2) pour a ≥ 1 au-delà de (1,1) — et la branche 3
  de son induction (l'argument p₁, p₂ ≥ o+1 n'a pas d'analogue immédiat
  quand les uns portent des valeurs libres) ; l'induction sur o
  transférerait ensuite. Puis : fibres composées, compression — la carte
  du front est inchangée par ailleurs.
