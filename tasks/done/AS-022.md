# AS-022 — THÉORÈME : la Conjecture 13 vaut inconditionnellement pour tout d ≤ K·log₂ n — première tranche prouvée à degré CROISSANT

- **Type** : T (théorème assemblé de briques prouvées + vérification numérique de chaque maillon)
- **Exécutée le** : 2026-07-02
- **Script** : [`checks/task_as022.py`](../../checks/task_as022.py)

## 1. L'énoncé

> **Théorème.** Pour tout n impair et tout d avec 2d+1 ≤ n :
> D(n, d, (n+1)/2) ≥ C(n−2d−1, (n−2d−1)/2) / 2^{d+3},
> d'où dist ≥ 2^{(n−3d)/2 − 2}/(2n)^{1/4}. En particulier, pour tout
> K constant et d ≤ (2K/3)·log₂ n :
> **dist ≥ 2^{n/2}/(4·(2n)^{1/4}·n^K)** — la Conjecture 13 de KV est
> vraie, inconditionnellement, sur toute la tranche d = O(log n).

C'est la première borne prouvée à d **croissant** (nos théorèmes
antérieurs : d ≤ 3 constant). La tranche d = O(log n) est strictement
incluse dans le régime de la conjecture (d = o(√n/log n)).

## 2. La preuve = deux briques déjà prouvées, jamais assemblées

1. **AS-011** (carte des seuils, duaux de sous-cube, inconditionnel) :
   la fenêtre de (2d+1, d, d+1) est [0, d] ∋ r=0 avec C(d,0)=1 impair
   ⟹ jamais exactement représentable ⟹ b_d := D(2d+1, d, d+1) ≥ 1/2^{d+3}
   pour TOUT d.
2. **AS-004** (padding (1,2,1) par restriction de 2 variables, sans
   hypothèse de symétrie), itéré : (1,2,1)^{*(m/2)} = C(m,·), et le
   terme central s'aligne sur le seuil central ⟹
   D(n,d,c) ≥ C(m, m/2)·b_d avec m = n−2d−1.
3. C(m, m/2) ≥ 2^m/√(2m) et 2^{n−2d−1}/2^{d+3} = 2^n/2^{3d+4}. ∎

La perte est exactement 2^{3d/2} : la route du padding meurt à
d ~ log n — c'est la quantification PRÉCISE de la frontière où commence
la tour dyadique (AS-017/020 : au-delà, il faut récupérer ~4^d par les
couplages de parité).

## 3. Vérifications (aucun maillon sans calcul)

- **A. Bases exactes** (énumération symétrique certifiée, dim d+1) :
  b_d = 5/32, 1/8, 93/512, 59/128, 13/32, 1/8 pour d = 2..7 — toutes
  ≥ 1/2^{d+3}, aucune nulle, et les Mersenne d = 3, 7 donnent
  exactement le 1/8 d'AS-012. (d=8 : cap d'énumération à 5·10⁷ nœuds,
  borne sup 1084343/131072 seulement — non concluant, non
  contradictoire ; le théorème n'en dépend pas.)
- **B. Convolution** sur cellules exactes : D(9,3,5) = 387/512 ≥
  7/32 + 2·(1/8) + 7/32 = 11/16. OK.
- **C. Chaîne complète** D(n,d,c) ≥ C(m,m/2)·b_d : 5/5 OK
  ((9,3), (11,3), (13,3), (13,5), (15,5)), ratios 2,95–7,62 (le mou
  vient de ne garder que le terme central — attendu).

## 4. Remarques

- Mesuré : b_d ≥ 1/8 pour tout 3 ≤ d ≤ 7 — si b_d = Θ(1) (plausible,
  non prouvé), la perte tombe à 2^d et la constante s'améliore
  (d ≤ K·log₂ n au lieu de (2K/3)·log₂ n) ; ne change pas la frontière
  log n.
- Antériorité : assemblage de NOS briques ; comme pour AS-008, le §7 de
  KV ne traite que la tranche Z = 0 et nous n'avons trouvé aucune borne
  asymptotique sur min_Z dans leur papier — la réserve « folklore »
  reste à poser à Krishan (point à ajouter à la synthèse).
- Ce qui reste pour la conjecture entière : log n → √n/log n, i.e.
  récupérer 4^d par les couplages — la tour dyadique, inchangée.
