## 1. Réduction préliminaire (complémentation mod 2)

Pour A ≠ ∅ ⊆ {1..k} (poids = valeurs), le coefficient ANF de
[Σ ≥ t] en A vaut la parité de #{U ⊆ A : Σ(U) ≥ t}
= (2^{|A|} − #{U : Σ(U) < t}) mod 2 = **parité de
#{U ⊆ A : Σ(U) < t}** — un énoncé de sommes de sous-ensembles pur.

## 2. La carte 2D (mesurée, k ≤ 12) — la loi vit dans une fenêtre

N(k,t) = 2^{j}−1 avec j = k pour t = 1 (OR) ; **j = k−1 pour TOUTE la
fenêtre 2 ≤ t ≤ k+1** ; puis une zone médiane irrégulière (non-puissances,
riche) ; puis une queue stabilisée universelle (… 3 3 (5) 2 2 1 1,
identique pour tout k ≥ 5, alignée sur t_max). La diagonale t = m de
F-018 est dans la fenêtre.

## 3. LE THÉORÈME (prouvé)

> **Pour k ≥ 2 et 2 ≤ t ≤ k+1 : la sparsité ANF de
> [Σ_{i∈U} i ≥ t] (poids {1..k}) vaut exactement 2^{k−1} − 1.**
> En particulier |ANF(THRW_m)| = N(m,m) = 2^{m−1}−1 (F-018, 19/19,
> maintenant démontré).

**Preuve** (induction de Shannon sur la variable de poids k).
Décomposition : S(k,t) = S(g₀) ⊔ z_k·(S(g₀) ⊕ S(g₁)), où g₀ = seuil t
sur {1..k−1}, g₁ = seuil t−k sur {1..k−1}.

- **Cas 2 ≤ t ≤ k** : t−k ≤ 0, donc g₁ ≡ 1 et ANF(g₁) = {∅}. Comme
  ∅ ∉ S(g₀) (car g₀(∅) = 0 pour t ≥ 1), S(g₀) ⊕ {∅} = S(g₀) ∪ {∅},
  d'où N(k,t) = 2N(k−1,t) + 1 = 2(2^{k−2}−1) + 1 = 2^{k−1}−1 par
  hypothèse d'induction (le bord t = k utilise le bord t = (k−1)+1 de
  la fenêtre précédente).
- **Cas t = k+1** : g₁ = [Σ ≥ 1] = OR_{k−1}, dont l'ANF est TOUS les
  monômes non vides (2^{k−1}−1). Comme S(g₀) ⊆ non-vides,
  |S(g₀) ⊕ All| = (2^{k−1}−1) − N(k−1,t), et le total TÉLESCOPE sans
  hypothèse d'induction : N(k,k+1) = 2^{k−1}−1.
- **Base k = 2** : N(2,2) = N(2,3) = 1. ∎

**Vérification mécanique** (k ≤ 12) : l'énoncé sur toute la fenêtre,
ET les deux cas de la récursion vérifiés AU NIVEAU DES ENSEMBLES
(égalité exacte des supports ANF prédits/calculés) — 3/3 OK.
