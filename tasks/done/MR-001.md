## 1. Observation structurelle (gratuite, via notre théorie)

- γ(1) = 0 pour tout γ ∈ L_{d,n} (divisibilité par 1−x). Pour n impair,
  t = (n+1)/2 : un vecteur **palindromique** a S_t = −S_{<t} = S_t ⟹
  **S_t = 0, toujours pair** — les palindromes ne certifient jamais MAJ.
- Les **décalages** (même norme) changent S_t : pour un vecteur PLAT
  (coefficients ±1), le placement qui ne laisse qu'un seul ±1 au-dessus
  de t donne S_t = ±1, **impair**. Prédiction : au plateau (minima plats),
  la condition de parité MAJ est satisfaite À LA NORME MINIMALE.

## 3. La dichotomie (le résultat)

**Le même réseau, deux fonctionnelles, deux phases :**
- **AND** (γ_n impair) : bloqué dans la bande par le bout pair du cœur
  2Φ₃+x (notre réfutation V-018/V-053, validée Krishan).
- **MAJ direct** (S_t impair) : **SERVI au plateau** — l'analogue de la
  Conjecture 5 pour MAJ est VRAI (témoins explicites) dans le régime
  d ≪ n, celui-là même de la Conjecture 1.5 de BHLR ; bloqué dans la
  bande cyclotomique comme AND.
- La carte de phase du réseau (V-046/V-050) acquiert un SENS de
  complexité : phase algébrique/cyclotomique = parité morte (les deux
  fonctionnelles) ; phase PTE/plate = parité vivante pour MAJ.

**Conséquence mécanique (via Claim 3.2 de KV, leur propre argument)** :
au plateau, tout polynôme torique symétrique de degré ≤ d approximant
MAJ_n subit ε ≥ 1/(2‖γ‖₁) avec γ = le vecteur plat minimal décalé —
p.ex. d = 10, 98 ≤ n ≤ 240 : ‖γ‖₁ = 28 ⟹ **ε ≥ 1/56, uniforme en n**
(borne certifiée par témoin explicite, degré constant / erreur constante).

## 4. Caveats honnêtes

- Le mécanisme est celui de KV (Claim 3.2 instancié à f = MAJ) — notre
  apport est la QUESTION (jamais posée), le CALCUL (minima réels + tous
  décalages) et la DICHOTOMIE de phase ; pas le cadre.
- Plateau : minima obtenus par le moteur symétrique (min_sym = λ₁
  conditionnel à V-042, d ≥ 8) ; bande : énumération exhaustive.
- La borne ε ≥ 1/(2‖γ‖₁) n'est PAS serrée en général (ε\*(7,1) = 3/16
  n'est pas de la forme 1/2k) — c'est une borne inf, pas une identité.
- Régime asymptotique (Conjecture 1.5) toujours hors de portée : ceci
  est une structure exacte aux petites tailles, pas une preuve.
