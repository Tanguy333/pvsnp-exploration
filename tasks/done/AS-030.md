## 1. Le théorème (réponse à la commande « renormalisation d'objets duaux sans perte »)

La valeur de classe h(π) = min_{S≡π(2)} ‖P_d(S+t)‖² est **invariante
par π ↦ π ⊕ c pour tout c ∈ RM(d,n)** (ajouter le vecteur entier 0/1
d'un polynôme booléen de degré ≤ d ne change pas la distance — AS-019
rendu théorème). De plus la base entière saturée C du complément des
monômes engendre mod 2 exactement le code dual RM(n−d−1,n) : le
syndrome C·π mod 2 indexe exactement les cosets. Donc :

> **h est une fonction sur les cosets de RM(d,n) — un objet FINI et
> EXACT** (2^{2^n − dim RM} valeurs), sans aucune perte.

Et RM(d−1,n) ⊂ RM(d,n) ⟹ le syndrome fin détermine le grossier ⟹

> **D(n+1,d,t) = min_{σ ∈ F₂^N/RM(d−1,n)} [½H_d(gros(σ)) + ½H_{d−1}(σ)]**

— la cascade de la Conjecture 13 est EXACTEMENT une récursion sur les
tables de cosets de Reed–Muller, couplées par le raffinement des codes.
C'est la renormalisation d'objets duaux sans perte : là où le
certificat-paire perdait 40 %/niveau (AS-029), la table ne perd RIEN.

## 3. Une loi naïve réfutée (honnêteté)

h n'est PAS une fonction du poids de chef de coset : à (3,1), le poids
de chef 1 donne h ∈ {1/8, 3/8, 5/8} selon le coset (mesuré). La cible
décalée δ/2 fait de h une variante NOUVELLE de la théorie classique
des poids de cosets — le dictionnaire direct (chefs, rayon de
recouvrement) ne suffit pas ; la porte vers cette littérature reste
ouverte mais l'objet est neuf. [Antériorité à auditer avant toute
communication : « lattice CVP sur classes de parité modulo RM » — nous

## 4. Ce que ça change pour la Conjecture 13

Le programme de preuve a maintenant une forme fermée : comprendre la
**récursion des tables de cosets RM** — comment les tables au niveau
n+1 se construisent depuis le niveau n, et pourquoi le min couplé sur
les cosets croît comme 2^n/poly (C13). L'obstacle quantitatif est
inchangé (la taille des tables croît : 2^{Σ_{j>d}C(n,j)}), mais l'objet
est exact, fini à chaque niveau, muni d'une structure de code
(raffinement RM, dualité, symétries affines de RM) — le bon habitat
pour chercher l'invariant de renormalisation qui manque. Prochain pas
mesurable : les tables à n=4 (32 cosets pour RM(2,4), 2048 pour
RM(1,4)) et la COMPARAISON n=3 → n=4 : la récursion des tables,
observée une fois.
