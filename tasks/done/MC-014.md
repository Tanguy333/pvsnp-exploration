## 1. Cadre

2 ≤ a ≤ b, ν = a + b, u = A, v = B disjoints. P_A = p(u) = W_A (tout le
poids pur-A s'active en u), P_B = W_B ; X = poids mixte ;
W = W_A + W_B + X. Classes : σ (singletons), h (hauts purs), π (paires
{i,j}), X^A₁/X^B₁ (mixte à côté singleton), R (mixte à deux côtés ≥ 2).
Δ := P_B − P_A, WLOG Δ ≥ 0 (échanger A et B — la cible est symétrique).
∅ est un zéro ⟹ P_A, P_B ≥ 1. E_j := Σ{a_S : S∖A = {j}} ≥ 1 et
F_i := Σ{a_S : S∖B = {i}} ≥ 1 (voisins hauts des uns) ; familles
disjointes ⟹ σ_B + X^B₁ ≥ b, σ_A + X^A₁ ≥ a.

## 2. LES OUTILS (prouvés)

**(T1) Réduction par tranche vers un point.** La restriction x_i := 1
(i ∈ A) élimine v de la tranche (B ∌ i) : la fonction tranchée est
[w′ = A∖{i}] sur ν−1 variables, séparée par le polynôme fusionné de poids
W − a_{{i}}. Par la loi G (MC-008) :
**W ≥ b + 1 + a_{{i}} pour tout i ∈ A** ; symétriquement
W ≥ a + 1 + a_{{j}} pour tout j ∈ B.

**(T2) Tranche pleine à deux valeurs protégées.** q(y) := p(A∪y) − P_A
est le polynôme fusionné de positions Ẽ_T = Σ{a_S : S∖A = T} (T ⊆ B non
vide), de poids EXACTEMENT W_B + X, avec Ẽ_{{j}} = E_j. Tout y ≠ ∅ donne
un zéro (A∪y ∉ {u, v}), d'où : **les valeurs de q sur y ≠ ∅ évitent
{0, Δ}**. Conséquences : (i) W_B + X ≥ b (les E_j ≥ 1, familles
disjointes) donc **W ≥ W_A + b** et symétriquement W ≥ W_B + a ;
(ii) si Δ = 1 : E_j ≠ 1 ⟹ **E_j ≥ 2 pour tout j** ⟹ W_B + X ≥ 2b.
Sur le cube B : p_B(B∖{j}) = P_B − D_j^B ∉ {P_B, P_A} ⟹ D_j^B ≥ 1 et
**D_j^B ≠ Δ**.

**(T3) Identité de comptage.** W ≥ a + b − π + h_A + h_B + R, d'où :
**W ≤ a+b+1 ⟹ h_A + h_B + R ≤ π + 1.** (*)

## 3. THÉORÈME PARTIEL — W ≥ a + b + 2 dans les régimes suivants

Supposons W ≤ a + b + 1 ; chacun des régimes suivants aboutit à une
contradiction, donc le minorant vaut dès que l'un d'eux s'applique :

1. **Un singleton lourd** : ∃ i avec a_{{i}} ≥ a + 1 (alors T1 donne
   W ≥ b + a + 2), ou ∃ j avec a_{{j}} ≥ b + 1.
2. **Un bloc pur lourd** : W_A ≥ a + 2 (alors T2-(i) donne W ≥ a+2+b),
   ou W_B ≥ b + 2.
3. **Structure haute** : h_A + h_B + R ≥ π + 2 (contredit (*)).
4. **Δ = 1, FERMÉ ENTIER** : par T2-(ii), W ≥ W_A + 2b ; si b ≥ a + 1 ou
   W_A ≥ 2, c'est ≥ a + b + 2 ✓. Reste (b = a, W_A = 1, P_B = 2) : les
   singletons de B sont des zéros de valeur a_{{j}} ∉ {P_A, P_B} = {1, 2}
   et a_{{j}} ≤ σ_B ≤ W_B = 2, donc a_{{j}} = 0 pour tout j ⟹ σ_B = 0 ⟹
   E_j = X^B_j ≥ 2 ⟹ X ≥ 2b ⟹ W = 1 + 2 + X ≥ 2b + 3 > a + b + 2. ∎
5. (Conséquences WLOG accumulées pour le résidu : a_{{i}} ≤ a,
   a_{{j}} ≤ b, W_A ≤ a + 1, W_B ≤ b + 1, h_A + h_B + R ≤ π + 1,
   Δ ∉ {1}.)

## 4. Le résidu — découpé, avec ses mécanismes candidats

**Résidu = { Δ = 0 } ∪ { Δ ≥ 2 }, sous les WLOG du §3.5.** Fait de
structure MESURÉ (mode `temoins`) : les six témoins optimaux extraits
((2,2)..(2,5)) vivent TOUS à **Δ = 0, W_A = W_B = 1, σ = 0** (deux
monômes pleins m_A, m_B + tout le poids en mixte) — le résidu est
exactement l'habitat des optima : c'est là que la loi est serrée, donc là
que le minorant est dur. Mécanismes de fermeture candidats, nommés :
- **Δ = 0** : le système d'échange des zéros w_{ij} = (A∖{i})∪{j} —
  p(w_{ij}) = P − D_i^A + E_j^{(∖i)} ≠ P donne un système de a×b
  diséquations « E-effectif ≠ D » dont la convexité devrait extraire le
  +2 (le tout-singletons meurt déjà sur les ensembles de niveau : à
  poids uniforme, w_{ij} touche exactement P) ;
- **Δ ≥ 2** : le saut au-dessus de Δ — toute chaîne maximale de q doit
  enjamber la valeur interdite Δ, un pas ≥ 2 par chaîne ; il faut un
  argument de coupe (combien de sauts disjoints la structure force).
