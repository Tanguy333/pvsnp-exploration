## 3. Trois lois de structure mesurées

1. **Compression massive** : H₁ vit sur 2048 cosets mais ne prend que
   **14 valeurs**, constantes sur les **180 orbites de S₄** (0 violation
   sur les 2048 cosets — l'invariance par permutation des variables est
   vérifiée exhaustivement). L'objet sans perte est effectivement
   PETIT : la renormalisation agit sur un espace d'orbites réduit, pas
   sur 2^{2^n} classes.
2. **Quantization dyadique** : les valeurs sont dans (1/2^n)·Z —
   granularité 1/8 à n=3, 1/16 à n=4 : le raffinement dyadique de la
   tour (AS-020) est VISIBLE dans le spectre des tables. (Loi mesurée ;
   preuve candidate : les dénominateurs de (CCᵀ)⁻¹.)
3. **Symétrie centrale** : au seuil central, les tables g/2 et δ/2 de
   même degré coïncident exactement.

Récursion n=3 → n=4 (première observation) : spectre {1/8, 3/8, 5/8}
(16 cosets) → 14 valeurs en 1/16 (2048 cosets) — la granularité se
raffine d'un facteur 2 par niveau, l'étendue double (5/8 → 2).
