## Verdict et acquis (détail dans la note)

1. **[NON TROUVÉ] sur les quatre lignes** — ni la taille ni le poids d'une
   forme profondeur-2 à tête symétrique depuis la table n'ont jamais été
   posés : les duretés s'arrêtent aux têtes OR (Masek/AHMPS, HOS18
   OR∘AND∘MOD_m — où la tête seuil est une extension spéculative jamais
   réalisée, verbatim) ; la tête seuil n'est que crypto-dure (Min-TC⁰,
   NP-complétude ouverte depuis 2005) ; SPP est Σ₂ᵖ-complet mais à
   entrée-FORMULE ; ESOP n'a aucune classification publiée ; le programme
   Simons 2023 (15 problèmes ouverts) ne nomme rien en profondeur-2
   symétrique.
2. **Recadrage de MC-001** : le motif « versions partielles dures » date de
   Levin 1973 (DNF-MCSP∗, 2ᵉ problème NP-complet de son papier) ; les
   points listés sont NP-complets pour circuits généraux depuis HJLT96 /
   ABF+08. Th.2/Th.3 = instances non publiées d'un motif établi — désormais
   sourcé (la fiche MC-001 le déclarait sans ancrage).
3. **Gabarit stratégique identifié** : HOS18 = le pipeline complet Th.8
   (partiel via Set Cover, analogue de notre Th.2) → **Th.16 (réduction
   partiel → total, randomisée zero-error, coût contrôlé par |f⁻¹(∗)|)** →
   Th.24 (dérandomisation par PRG). L'étape Th.16 est exactement celle qui
   manque au front — son transfert à la tête SYM pondérée, ou l'obstruction
   du zoo, est la question précise. → ligne backlog [auto].
4. **Cohérence de régime** : les classes restreintes admettent des duretés
   DÉTERMINISTES many-one (Masek, HOS18) ; Kabanets-Cai ne mord que le MCSP
   général. Rien n'interdit une NP-complétude déterministe de MinSYM+.
5. **Prises annexes** : le concurrent de HIL — Gaspers-He-Mackenzie,
   arXiv:2508.05597 (NP-complétude de CC déterministe revendiquée, préprint,
   lemme retiré entre v3 et v4 : précaution) — candidate cellule 17 ;
   HIL CCC 2021 (rondes constantes, la question méta posée dès 2021) ;
   Loff-Milovanov TR24-034 (decision tree depuis la table) ; l'extension
   NOF de HIL n'existe pas (0 résultat, vérifié trois voies).
