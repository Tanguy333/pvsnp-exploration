## 1. Le moteur (l'arme neuve du fil)

Dans la classe décomposable, la séparation se vérifie SANS cube 2ⁿ :
DP exacte sur les états (m = # blocs satisfaits, s = somme) — coût
polynomial. v2 ajoute : (i) DP **incrémentale** le long du DFS
(push/pop) ; (ii) **élagage partiel SAIN** — toute collision parmi
les blocs déjà choisis tue la branche, car les blocs restants peuvent
rester non satisfaits (valeur 0), donc toute collision partielle
survit au système complet ; (iii) **approfondissement itératif** sur
le poids total — chaque niveau « vide » est une borne inférieure
PROUVÉE, l'optimum exact sort en premier. Gain mesuré : k = 5 en
25 s (v1) → 0 s (v2) ; k = 7 en 17 s ; k = 8 en 68 s.

## 3. Structure pour la preuve générale (T26-S2 candidat)

1. **Reformulation** : la valeur du bloc à l'état 11 = son poids →
   W = Σ (valeurs-sommets) ; le sous-lemme dit « moyenne des sommets
   ≥ k+1 ».
2. **Système d'évitement (dérivé, sain)** : la séparation implique
   que toute valeur satisfaite v de tout bloc évite toutes les sommes
   signées d'au plus t−1 différences prises dans les autres blocs
   (en particulier chaque différence individuelle M_i−a_i, M_i−b_i,
   b_i−a_i de chaque autre bloc). Le témoin mod-k réalise l'évitement
   arithmétiquement (différences ∈ {0, ±k}, valeurs ≡ 1 mod k).
3. **Indice de t-indépendance** : la borne k(k+1) est identique à
   t = 2 (k = 3, 4), t = 3 (k = 5, 6), t = 4 (k = 7, 8) — la preuve
   générale ne doit rien devoir au seuil médian.
