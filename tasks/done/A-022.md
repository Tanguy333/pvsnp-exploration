## Ce qui a été fait

1. **La flèche CORRIGÉE** : MP91 p. 318 (équivalence en texte
   courant, « this question is equivalent to the P = NP question ») +
   dérivation standard — pas de théorème numéroté ; MP91 Th. 2.1
   (NP-dureté ⟺ NP = coNP) et l'absence attendue de TFNP-complet
   (classe sémantique) consignés comme verrous structurels.
2. **Fondations verbatim** : P94 (classes par principe d'existence,
   Propositions 1/3/4, complétudes 3D-Sperner/Brouwer/Nash-membership,
   la calibration 1D TEXTUELLE — « 1D-SPERNER represents FP » ;
   PPADS absent de P94, nommé par BCEIP) ; Nash PPAD-complet (DGP
   2009, Chen-Deng-Teng 2009) ; **CLS = PPAD ∩ PLS** (FGHS,
   inconditionnel) ; EOPL/SOPL (GHJMPRT — « nine months » d'échec
   boîte-noire avant le renversement).
3. **Route crypto** : BPR 2015 (obfustopia) → CHKPRR 2019
   (Fiat-Shamir/sumcheck) → JKKZ 2021 (LWE sous-exp) → TCC 2022 (LWE
   poly + IS) / KLV (DDH sous-exp) ; « LWE poly seul » [NON TROUVÉ] ;
   limite interne RSS (la dureté PPAD moyenne ne donne pas d'OWF).
4. **Frontière ligne 15 TRANCHÉE** : recouvrement FORT (les
   caractérisations Θ de Göös et al. JACM 2024, PLS ↔ Resolution,
   PPAD ↔ uNS…) mais STRICTEMENT boîte-noire — les textes déclarent
   la question uniforme hors de portée de ces équivalences.
5. **Frontière ligne 16 TRANCHÉE** : niveaux distincts par théorème
   relativisé (TFNP vs TFΣ₂, vérifieur NP vs coNP ; monde BFKRV 2010)
   avec ponts 2024-2026 nommés (FNP ⊆ PEPP ; GLS-D STOC 2026 ;
   Chen-Li) — l'angle manqué par la candidature, désormais sourcé.
6. **Barrières** : algébrisation TUE (0 occurrence sur ~15 textes,
   AW08/BGS non cités) ; relativisation = la MÉTHODE même du régime
   inconditionnel (BCEIP Th. 1 : type-2 ⟺ tout oracle) ; l'analogue
   RR publié vit sur la ligne 16 (Korten).
7. **Folklore-check de la table Sperner (PR-004)** : 1D textuel dans
   P94 ; 2D — référence serrée Crescenzi-Silvestri 1998 (Ω(√n)) +
   FISV (O(√n), « tightness was not known before ») : Θ(k) linéaire,
   nos 3, 4, 6 compatibles ; valeurs exactes petit k [NON TROUVÉ] =
   réplication + constantes.
8. **Ligne 20 créée** : matrice (intégrité 22 × 8 vérifiée), en-tête,
   README (19 → 20) ; 14 extractions versionnées `bib/pdf/tfnp/`.
