## Pourquoi c'est non-trivial (rappel)

La coïncidence n'est PAS l'identité naïve « sommer les indicateurs des
termes du DNF » : l'indicateur d'un AND à `a` littéraux négatifs a une
weight L1 de `2^a` dans la base 0/1, donc le DNF minimal sommé coûte bien
plus que `#termes`. L'optimum L1 = #termes exige une représentation signée
plus fine — dont la structure est inconnue.

Le profil par degré le confirme : le minimum exige le degré **plein**
(121 à D=10, déjà 153 à D=9, 249 à D=8) — la représentation optimale
utilise le monôme complet.
