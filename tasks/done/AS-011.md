## Théorème (inconditionnel, les deux sens, tout seuil)

Pour n > d ≥ 1, 1 ≤ w ≤ n, f = THR_w sur {0,1}ⁿ, et
R(n,d,w) = [max(0, w−n+d), min(d, w−1)] :

> **∃ Z : {0,1}ⁿ → Z et p multilinéaire de degré ≤ d avec
> p = Z + THR_w/2 exactement ⟺ R(n,d,w) ne contient AUCUN sous-masque
> binaire de d** (r est un sous-masque de d ssi (r AND d) = r, i.e.
> C(d,r) impair, par Lucas).
> Sinon : D_full(n,d,w) ≥ 1/2^{d+3}.

## Preuve (généralisation directe d'AS-010)

(⟸) Les appariements stencil valent ⟨γ⁽ⁱ⁾, THR_w⟩ = ±C(d, w−1−i) pour
i ∈ [0, n−d−1] (sommes alternées partielles ; hors fenêtre : 0). Tous
pairs ⟺ aucun r ∈ R avec C(d,r) impair ⟺ (Lucas) R sans sous-masque de
d ⟹ D_sym = 0 (critère exact du quotient défini positif) ⟹ témoin
symétrique = témoin. (⟹) Pour r ∈ R avec C(d,r) impair : le dual de
sous-cube à s = w−1−r uns fixés (s ∈ [0, n−d−1] ✓) donne un η entier
⊥ V_d avec ⟨η, f⟩ = ±C(d,r) impair ⟹ aucune représentation exacte, et
dist ≥ (1/2)/2^{(d+1)/2}. ∎

## Cohérences remarquables

- n = 2d−1, w = d : R = [1, d−1] ⟹ AS-010 (cas particulier).
- KV Théorème 1.4 (d = 2^t, n = 2d+1, w = d+1) : R = [0, d] contient 0

- La carte à n = 31 : 49 cellules exactes sur 930, en structure fractale
  binaire (colonnes w ∈ {8, 16, 24}, plages de d) — le lieu exact est
  rare et arithmétique.

## Portée pour la Conjecture 13 et au-delà

La carte donne, pour chaque (n,d), les seuils « morts » (D = 0) et un
plancher explicite 1/2^{d+3} partout ailleurs — le socle exact sur lequel
le « bombage » (AS-006) s'accumule. Le couple AS-010/AS-011 est le
