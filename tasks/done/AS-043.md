# AS-043 — La courbe c(n,d) aux échelles modérées : le profil d'annulation est UNIVERSEL et c reste dans une bande [0,7 ; 1,5] sur toute la grille — pas de croissance détectable

- **Type** : V (mesure de l'objet équivalent à C13 sur une grille 6 cellules)
- **Exécutée le** : 2026-07-20
- **Scripts** : [`checks/task_as043.py`](../../checks/task_as043.py) (phase 1) + [`checks/task_as043b.py`](../../checks/task_as043b.py) (phase 2)

## 1. La méthode (échelles modérées, décision utilisateur)

La loi d'AS-042 (ln(1/ρ) = π/x − c) permet d'estimer c SANS payer les
petites échelles : estimateur ponctuel c(x) = π/x − ln(1/ρ(x)) à x
modéré (biais systématique en x → comparaison entre cellules À MÊME x),
plus ajustement 2 points par cellule (la pente doit retomber sur π :
contrôle de la loi). Échelles {1,6 ; 0,8 ; 0,4} (+0,2 aux petites
dimensions). D de référence aux nouvelles cellules : témoin exact
AS-021 (borne sup certifiée). Coût total ~19 min — la phase 1 a brûlé
son budget sur un x=0,2 déjà connu d'AS-042 (recalcul inutile, mais
cohérence 3,036e-7 vs 3,04e-7 : contrôle involontaire réussi).

## 3. Les trois verdicts

1. **La loi π est confirmée 6/6** : toutes les pentes ajustées tombent
   entre 3,16 et 3,34 (π = 3,142 ; biais positif décroissant quand x
   décroît, cohérent avec un terme correctif +O(x)). La loi d'AS-042,
   découverte sur 2 cellules, tient sur les 6.
2. **UNIVERSALITÉ du profil** : à x fixé, ρ est quasi identique sur
   toute la grille (x=1,6 : 0,49-0,62 ; x=0,8 : 0,056-0,085 ; x=0,4 :
   0,9-1,1·10⁻³) alors que 4D varie de deux ordres de grandeur —
   l'annulation de Lucas suit UNE courbe universelle e^{−π/x}, à
   correction O(1) près, indépendante de la cellule.
3. **c ne croît pas** : bande totale [0,70 ; 1,49] sur la grille. À
   d=3, c DÉCROÎT puis stagne en n (1,17 → 0,80 → 0,88 à x=0,4) ; à
   d=2, dérive douce vers le haut (0,82 → 0,87 → 1,06), de l'ordre du
   biais de l'estimateur (~±0,3). **Aucune explosion nulle part.**

## 4. Portée et limite honnête

C'est le soutien empirique le plus direct produit par le programme :
l'objet exactement équivalent à C13 (le scalaire c) est mesuré PLAT à
la précision atteignable, sur des cellules dont la profondeur du trou
varie de 3 à 358. Limite : les échelles modérées ont un biais O(x) du
même ordre que les variations observées, et une croissance LENTE
(log n) resterait indétectable sur 3 valeurs de n — la mesure soutient
c = O(1)..O(polylog), elle ne le prouve pas. Régime toujours n ≫ 2d ;
le régime d ~ √n/log n reste hors de portée de la boucle.
