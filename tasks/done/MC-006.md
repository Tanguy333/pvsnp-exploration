## 1. Définitions et énoncé

Variables partitionnées en blocs disjoints Z ⊔ X₁ ⊔ … ⊔ X_k. Pour un point
w, p(w) = Σ_{S ⊆ supp(w)} a_S avec a_S ∈ ℕ, S monôme positif non vide ;
W(h) = min Σ a_S sur les p à ensembles de valeurs disjoints sur h⁻¹(1) et
h⁻¹(0) (le modèle SYM+ du dépôt, A-013).

**Théorème MC-006.**
**(i) [Fibres à blocs disjoints — pas de partage.]** Soient des motifs
σ₁, …, σ_k ∈ {0,1}^Z (non nécessairement distincts) et des fonctions fᵢ
sur Xᵢ telles que, pour chaque i, la tranche « Z := σᵢ, Xⱼ := 0 pour tout
j ≠ i » réalise fᵢ : h(σᵢ, 0, …, xᵢ, …, 0) = fᵢ(xᵢ). h est ARBITRAIRE
partout ailleurs. Alors **W(h) ≥ Σᵢ W(fᵢ)**.
**(ii) [Sélecteur à un bit — strict.]** Si h = MUX_z(f, g) — h(1, x, y) =
f(x) et h(0, x, y) = g(y) pour tous x, y — et si le bras z = 0 (g) est non
constant, alors **W(h) ≥ W(f) + W(g) + 1**.
**(iii) [Serrage.]** La borne (ii) est atteinte : dès 1+1 variables
(W(MUX(id, id)) = 3 = 1 + 1 + 1) et sur 21 des 105 paires 2+2 (témoin :
f = masque 2, g = masque 8 → W = 4 = 3 + 1).

## 2. Preuves

### (i) — l'argument de charge

Soit p = Σ a_S m_S un séparateur optimal de h, de poids W(h). Pour chaque
i, définissons la **classe de charge**
𝒞ᵢ := { S : S ∩ Xᵢ ≠ ∅ et S ∩ Xⱼ = ∅ pour tout j ≠ i }
(la partie Z de S est libre). Les 𝒞ᵢ sont **deux à deux disjointes** : un
monôme de 𝒞ᵢ ∩ 𝒞ⱼ (i ≠ j) devrait avoir S ∩ Xᵢ à la fois non vide (𝒞ᵢ) et
vide (𝒞ⱼ).

Restreignons p à la tranche i. Le support d'un point de tranche est
supp(σᵢ) ∪ supp(xᵢ), donc les monômes actifs vérifient S_Z ⊆ supp(σᵢ),
S_{Xᵢ} ⊆ supp(xᵢ), S_{Xⱼ} = ∅ (j ≠ i) :
p|ᵢ(xᵢ) = cᵢ + qᵢ(xᵢ), où cᵢ (les monômes ne touchant aucun bloc X) est
constant sur la tranche, et
qᵢ(xᵢ) = Σ_{∅ ≠ T ⊆ Xᵢ} bᵢ_T · m_T(xᵢ), avec
bᵢ_T = Σ { a_S : S ∩ Xᵢ = T, S ∩ Xⱼ = ∅ ∀j≠i, S_Z ⊆ supp(σᵢ) } ∈ ℕ.
qᵢ est donc un polynôme légal du modèle (monômes positifs non vides de Xᵢ,
coefficients entiers ≥ 0).

La disjonction GLOBALE des ensembles de valeurs de p sur h se restreint à
la tranche : les valeurs de p|ᵢ sur fᵢ⁻¹(1) et fᵢ⁻¹(0) sont disjointes ; le
décalage commun cᵢ ne change rien ; donc **qᵢ sépare fᵢ**, d'où
W(fᵢ) ≤ poids(qᵢ) = Σ_T bᵢ_T ≤ poids(𝒞ᵢ)
(la dernière inégalité : chaque a_S de la somme est compté au plus une fois
et appartient à 𝒞ᵢ ; supprimer la contrainte S_Z ⊆ supp(σᵢ) ne fait
qu'agrandir). Par disjonction des classes :
Σᵢ W(fᵢ) ≤ Σᵢ poids(𝒞ᵢ) ≤ poids total = W(h). ∎

*Remarques.* (a) La distinction des motifs σᵢ n'est jamais utilisée.
(b) h est libre hors des k tranches — c'est ce que le test T3
(tranches-poubelle) éprouve.

### (ii) — la contradiction de collision

Ici Z = {z}, X₁ = X (bras z = 1, fonction f), X₂ = Y (bras z = 0,
fonction g), et h est spécifiée sur les DEUX tranches pleines. Partitionnons
les monômes : 𝒞_f = {S_X ≠ ∅, S_Y = ∅} (z libre) ; 𝒞_g = {S_Y ≠ ∅,
S_X = ∅} (z libre), scindée en B₀ (sans z) et B₁ (avec z) ; le reste
R = {S touchant X et Y} ∪ {{z}}. Donc W(h) = w(𝒞_f) + B₀ + B₁ + w(R).

Par (i) appliqué aux tranches (z=1, y=0) et (z=0, x=0) :
W(f) ≤ w(𝒞_f) — tous les monômes de 𝒞_f sont vus, S_Z ⊆ {z} étant sans
contrainte — et W(g) ≤ B₀ — sur la tranche z = 0, les monômes contenant z
sont inactifs.

Supposons W(h) = W(f) + W(g). Alors :
W(f) + W(g) = w(𝒞_f) + B₀ + B₁ + w(R) ≥ W(f) + W(g) + B₁ + w(R),
donc **B₁ = 0, w(R) = 0** (en particulier a_{{z}} = 0 et aucun monôme
mixte X-Y), w(𝒞_f) = W(f), B₀ = W(g). Les seuls monômes restants sont :
pur-X ou z∪X (classe 𝒞_f), et pur-Y (B₀). Notons Q le polynôme pur-Y.

Évaluons sur l'axe x = 0 : pour tout y,
p(1, 0, y) = a_{{z}} + [monômes zY] + [monômes pur-Y ⊆ supp(y)]
           = 0 + 0 + Q(y) = **Q(y)** ;
p(0, 0, y) = **Q(y)** également.
Or h(1, 0, y) = f(0) pour tout y, et h(0, 0, y) = g(y). Comme g est non
constante, il existe y* avec **g(y*) ≠ f(0)** (si f(0) = 1, un zéro de g ;
sinon un un de g). Les deux points (1, 0, y*) et (0, 0, y*) ont la même
valeur Q(y*) et des classes opposées — la disjonction des ensembles de
valeurs est violée. Contradiction. ∎

*Remarque d'asymétrie.* La preuve n'utilise que la non-constance du bras
z = 0 (le MUX n'est pas symétrique en z pour des monômes positifs) ;
l'énoncé est donné pour f, g non constantes, le périmètre de la campagne.

### (iii) — serrage

W(MUX(id, id)) = 3 sur 3 variables (calcul exhaustif sans solveur, T1) =
1 + 1 + 1 ; et 21 des 105 paires 2+2 réalisent l'écart exactement +1
(témoin re-vérifié : f = 2, g = 8, W = 4 = 3 + 1). La borne (ii) est donc
optimale comme borne uniforme.

## 4. Ce que le théorème donne au front — et ce qu'il ne donne pas

**Donne.** (a) Le fondement du schéma de totalisation, PROUVÉ à toute
taille dans la géométrie blocs-disjoints : le coût des fibres sélectionnées
ne se partage jamais — c'était l'exigence n°1 identifiée par MC-004, et
l'issue « partage » aurait tué le schéma. (b) Un **outil de certification**
inédit pour le fil : le k-bras donne des familles dont W est minoré PAR
THÉORÈME (W ≥ Σ W(fᵢ)) — premier levier contre le verrou « certifiabilité
de W aux tailles d'une vraie réduction » (MC-001, verrou (c)) ; encadré par
B1 (MC-005) vers le haut. (c) Avec (ii)-(iii), la version 1-bit est
résolue exactement au +1 près.

**Ne donne pas — le verrou requalifié.** Une totalisation POLYNOMIALE ne
peut pas offrir un bloc frais à chaque ∗-point : k fibres à blocs disjoints
coûtent ≥ k variables, donc une table de taille ≥ 2^k — exponentielle dès
que k dépasse O(log). Or nos instances partielles NP-complètes (Th.3) ont
presque toute la table en ∗. La géométrie qu'exige la polynomialité est
celle de HOS18 : **fibres à coordonnées PARTAGÉES** (leur s = O(t log m)
sert TOUTES les fibres). Dans cette géométrie, les classes de charge du
présent argument se recouvrent — c'est exactement là que vivent le
mécanisme antichaîne de MC-003 et le zoo. **Verrou nommé : la
super-additivité (ou sa version affaiblie contrôlée) pour des fibres à
support partagé** — candidat MC-007. La compression (Th.8) reste l'autre
verrou, inchangé.
