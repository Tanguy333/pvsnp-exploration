## 3. Le fait central : q(n, 3) = 1/1024 pour n = 4, 5, 7 — trois points certifiés

La distance² double exactement avec n (dist² = 2ⁿ/1024) : **ρ(n, 3) est
constant**. Si cette n-invariance vaut pour chaque d fixé avec la
décroissance observée (q_d = 19, 5, 1 /1024 pour d = 1, 2, 3), alors en
prenant d(n) = √n/log²n = o(√n/log n) on aurait ρ ~ exp(−Θ(d)) ≪
1/poly(n) — **la Conjecture 13 serait fausse**. Statut : trois points
certifiés à d = 3, deux à d = 1, 2 — évidence structurelle, pas preuve.

**La voie vers un théorème (AS-004)** : MAJ_{n+2}(x, 1, 0) = MAJ_n(x) —
le padding (une variable à 1, une à 0) préserve MAJ en décalant le seuil.
Si ce plongement transporte les certificats/minimiseurs, il peut PROUVER
q_d(n+2) ≤ q_d(n) (voire l'égalité) — la n-invariance deviendrait un
lemme, et la décroissance en d mesurée ferait le reste. C'est l'analogue
ℓ₂ du Claim 3.1 de KV (leur propre astuce de fixation de variables),
appliqué dans la direction qu'ils n'ont pas regardée.
