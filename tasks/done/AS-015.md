## Théorème (identité exacte)

Pour tous n, d ≥ 1, t, avec f_w = THR_w sur {0,1}ⁿ, δ = f_t − f_{t−1}
(= −Δ_{t−1}, la fonction delta de KV) et g = f_t + f_{t−1} :

> **D(n+1, d, t) = min { ½‖P_d(S + g/2)‖² + ½‖P_{d−1}(Z′ + δ/2)‖² :
> S, Z′ ∈ Z^{2ⁿ}, S ≡ Z′ (mod 2) }**

**Corollaire (borne découplée).** Comme g/2 ≡ Δ_{t−1}/2 (mod 1) :

> **D(n+1, d, t) ≥ ½·D_Δ(n, d, t−1) + ½·D_Δ(n, d−1, t−1)**

où D_Δ(n, d, w) = min_Z ‖P_d(Z + Δ_w/2)‖² — le terme de couplage en
degré **d−1** prédit par AS-014, et il porte sur **les Δ_w de KV
eux-mêmes** : la boucle entre leur §3 (les tradeoffs Δ_w) et la
Conjecture 13 (MAJ) se referme structurellement.

## Preuve

1. **Multilinéarité** : tout p de degré ≤ d sur n+1 variables s'écrit
   p(x, a) = p₀(x) + a·q(x) avec deg p₀ ≤ d, **deg q ≤ d−1**.
2. **Fibres** : ‖·‖² sur le (n+1)-cube = fibre a=0 + fibre a=1 :
   ‖y₀ − p₀‖² + ‖y₁ − p₀ − q‖², y_a = Z_a + f_{t−a}/2.
3. **Min sur q ∈ W_{d−1}** : le 2ᵉ terme devient ‖P_{d−1}(y₁) − P_{d−1}p₀‖².
4. **Décomposer p₀ = p′ + e**, p′ ∈ W_{d−1}, e ∈ E = W_d ⊖ W_{d−1} ;
   min sur p′ : le 1ᵉʳ terme devient ‖P_{d−1}(y₀) − e‖², et P_{d−1}p₀ = e.
5. **Parallélogramme** : min_e [‖A₀−e‖² + ‖A₁−e‖²] = ½‖A₀−A₁‖² +
   2·dist²((A₀+A₁)/2, E) = ½‖P_{d−1}(y₀−y₁)‖² + ½‖P_d(y₀+y₁)‖²
   (le complément de E dans W_{d−1}^⊥ est W_d^⊥).
6. **Changement de variables** : (Z₀−Z₁, Z₀+Z₁) parcourt exactement les
   paires (Z′, S) de même parité coordonnée par coordonnée. ∎

Le corollaire suit en découplant les deux minima et en notant que la
classe de g/2 (valeurs 0, ½, 1) ≡ Δ_{t−1}/2 modulo les entiers. ∎
