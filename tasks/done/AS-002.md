Conjecture 13 de KV (≥ 1/poly(n) conjecturé pour d = o(√n/log n)).

colonnes unimodulaire — saturation exacte par construction, vérifiée) ;

la base duale mise à l'échelle + **plongement de Kannan** sur nos moteurs
(turbo_lll + turbo_below, filtre |dernière coord| = W). Résultat en
**rationnels exacts**. Garde-fou : cellule marquée NON CERTIFIÉE si les
entrées dépassent 2²⁵ (GSO float).

**Validation** : n=3 reproduit exactement le scan par boîte indépendant

## 3. Observations (et leur statut)

1. **n-invariance exacte 4→5** : q_d identique (19, 5, 1)/1024 — dist²
   double exactement avec n. Si cette invariance persistait avec q_d
   géométrique en d, alors à d ~ √n/log n on aurait ρ ~ 2^{−Θ(d)} ≪
   1/poly(n) : **signal structurel CONTRE la Conjecture 13** (le même
   genre de motif que le ±2 contre la Conjecture 5). STATUT : indication
   à 2 points, PAS une réfutation (énoncé asymptotique, slack poly).
2. **⚠ CONVENTION (à corriger avant toute interprétation des n pairs)** :
   notre t = (n+1)//2 = « au moins la moitié » ; KV définissent MAJ =
   « *more than half* » (t = n/2+1 pour n pair). Les lignes n = 4, 6
   ci-dessus utilisent NOTRE convention — la légère casse de l'invariance
   à n=6 (5→7, 19→20,25) peut être un artefact de seuil. **La chaîne
   propre KV-conforme est n impair : 3 → 5 → 7.** Le point décisif est
   n=7 (d=1..4, rangs 120/99/64/29).
3. **Représentations exactes** (dist = 0) : (n=3, d=2) et (n=6, d=4,
   notre convention) — MAJ/2 + Z ∈ V_d exactement. Structurel, cohérent
   avec le régime « degré n−1 » de KV et leur Thm 1.4 (leurs upper bounds
   surprenants) ; les Z\* réalisants sont des objets à cataloguer.

## 4. Ingénierie (leçon + fix pour AS-003)

(6,3) : MemoryError dans turbo_below — la borne d'énumération utilisait
val0 (v=0), très au-dessus de dist², d'où ~1,3·10⁹ vecteurs sous le rayon.
Fix : borne = ub + W² avec ub obtenu par descente locale (Babai/rounding)
AVANT l'énumération, et W² > ub/3 suffit à exclure k = ±2. Nécessaire
aussi pour n = 7 (rangs ≥ 64).
