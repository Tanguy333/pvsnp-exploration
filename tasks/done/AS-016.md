## Théorème (cascade universelle — même preuve qu'AS-015, rien de spécifique aux seuils)

Pour TOUTE f : {0,1}^{n+1} → {0,1}, de fibres f₀ = f(·,0), f₁ = f(·,1) :

> **D_f(n+1, d) = min_{S ≡ Z′ (2)} [½‖P_d(S + (f₀+f₁)/2)‖² + ½‖P_{d−1}(Z′ + (f₀−f₁)/2)‖²]**
> et, classes modulo entiers : (f₀±f₁)/2 ≡ ½·1_{f₀⊕f₁} (le XOR des fibres),
> d'où **D_f(n+1, d) ≥ ½·D_h(n, d) + ½·D_h(n, d−1)**, h = f₀ ⊕ f₁.

La preuve est celle d'AS-015 mot pour mot (multilinéarité, fibres,
moindres carrés orthogonaux, parallélogramme, parités) — aucune étape
n'utilisait la structure de seuil. Les deux classes coïncident car ±½ et
+½ diffèrent d'un entier point par point.

## La dynamique symétrique : Pascal mod 2

Pour f symétrique de support de poids W : f₀ ⊕ f₁ a pour support
**W Δ (W−1)** — la multiplication par (1+x) sur F₂. Donc :
- un seuil [t, ·] → le delta {t−1} (AS-015 retrouvé) ;
- un delta {w} → la paire {w−1, w} → {w−2, w} → … → **les lignes de
  Lucas** : après k pas, support = {w−k+j : C(k,j) impair}, qui se
  **re-concentre en 2 points aux k = 2^m** (Sierpinski).
- Le fil entier est UN phénomène : la convolution (1,2,1) (AS-004), le
  lieu exact binaire (AS-010/011), le fantôme de parité (AS-013) et la
  cascade sont les visages d'une seule dynamique de Pascal mod 2.

## Corollaire déroulé (prouvé par itération) et le point dur

En itérant k pas depuis MAJ sur N = n+k+1 variables :
> D_MAJ(N, d) ≥ 2^{−k} Σ_j C(k, j) · D_{ligne-de-Lucas}(n, d−j)
— une **moyenne binomiale sur les chutes de degré** (j ~ Bin(k, ½)) des
distances des classes de Lucas (avec troncature au bord à suivre pas à
pas — la description « ligne de Lucas » vaut loin du bord ; l'identité
par pas vaut toujours). Pour d−j < 0 : D = ‖classe‖² (norme pleine).

**AS-017 (le point dur restant)** : évaluer asymptotiquement cette
moyenne au régime N ~ d² — les chutes de degré consomment d en ~2d pas
(Bin(k,½) concentré à k/2), après quoi les termes valent des normes
pleines de lignes de Lucas tronquées, pondérées 2^{−k}C(k,j). C'est LE
calcul qui dira si la cascade prouve la Conjecture 13 à perte près, ou
si le découplage par pas perd trop (les 2 cellules strictes montrent
qu'il perd parfois). AUCUNE claim ici — c'est une évaluation à faire,
pas un résultat.
