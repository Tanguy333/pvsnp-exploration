## Les prises (résumé du dossier)

1. **La flèche absente est structurelle** : le Lemme 5.2 a deux
   machines (temps M1 — n'utilise que coNP = NP et NP = P ; espace M2 —
   utilise P = NL) ; l'hypothèse minimale du Lemme 5.5 est une économie
   d'ESPACE ; toutes les cases de la Figure 7 opposent des ressources
   de natures différentes. Inférence machine par machine à confirmer
   sur le Lemme 3.4 à l'audit.
2. **« Troisième mécanisme non-relativisant »** : second exemplaire de
   l'accès à l'oracle (HCC+93/Fortnow 1994) que la ligne 1 nomme déjà
   pour Williams 2025 — et intrinsèquement muet sur P vs NP (les deux
   côtés polynomiaux).
3. **« Type de cellule nouveau »** : un win-win standard (Kannan 1982 ;
   CHR 2024) que la matrice n'a simplement jamais nommé — mécanisme
   transversal, pas type.
4. **Corrections** : Figure 7 ligne 5, P ≠ PSPACE est en colonne NON
   (Thm 4.6) ; le plafond positif est O(log n) (Conclusion, verbatim),
   pas une constante ; la version erronée est la conférence [6], le
   texte arXiv est le corrigé.
5. **Dormance et histoire** : Zhang et al. TCS 2020 existe ; le
   programme de Post a échoué pour ≤_T (Friedberg-Muchnik 1956-57) et
   a été vindiqué en 1991 (Harrington-Soare, PNAS 88) — pour une
   séparation déjà acquise par diagonalisation, la position exacte de
   BFvMT.
