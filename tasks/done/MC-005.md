## 1. Les deux bornes génériques (PROUVÉ, vérifié 588/588)

**Lemme B1 (appariement).** Soient f, g sur des ensembles de variables
disjoints, p_f, p_g des séparateurs optimaux, V_f := max_x p_f(x). Pour
toute h(x, y) dont la valeur ne dépend que du couple (f(x), g(y)) :
p := p_f + (V_f + 1)·p_g est un séparateur de h, donc
**W(h) ≤ W(f) + (V_f + 1)·W(g) ≤ W(f) + (W(f) + 1)·W(g)**.
*Preuve.* p est légal (monômes positifs non vides, coefficients ℕ). Comme
0 ≤ p_f(x) ≤ V_f, la valeur p(x,y) détermine le couple (p_f(x), p_g(y))
par division euclidienne par V_f + 1 ; chaque valeur de p_f (resp. p_g)
appartient à une seule classe de f (resp. g) par disjonction des ensembles
de valeurs ; donc la valeur de p détermine (classe_f, classe_g), donc la
classe de h — deux points de classes différentes ont des valeurs
différentes. ∎ (V_f ≤ W(f) car p_f(x) ≤ Σ a_S.)

**Lemme B2 (restriction).** Si une tranche (affectation y₀ des variables
hors x) réalise f — h(·, y₀) = f — alors **W(h) ≥ W(f)**.
*Preuve.* Soit p optimal pour h. p(x, y₀) = c₀ + q(x) où c₀ est le poids
des monômes purs-y actifs en y₀ et q(x) = Σ_{S : S_x ≠ ∅, S_y ⊆ supp(y₀)}
a_S·[S_x ⊆ supp(x)] — polynôme légal de poids ≤ W(h). La disjonction des
ensembles de valeurs de p sur h, restreinte à la tranche, donne celle de
c₀ + q sur f ; le décalage commun c₀ ne change rien ; donc q sépare f. ∎
Les quatre combineurs testés ont des tranches réalisantes pour f ET pour g
(∧ : un 1 de l'autre facteur ; ∨ : un 0 ; ⊕ : un 0 — et un 1 donne ¬f, de
même poids par MC-001 ; MUX : z fixé), donc **W(h) ≥ max(W(f), W(g))**
partout.

Vérification numérique : 588 tests, **0 violation** de B1, **0 violation**
de B2 (`checks/mc005_additivite.py bornes`).

## 2. La mesure (exhaustif 2+2 : 105 paires ; famille NOR jusqu'à 7 variables)

Détail complet : `data/mc005_additivite.md`. L'essentiel :

1. **MUX — le sélecteur, la forme même du schéma Th.16 — est STRICTEMENT
   super-additif sur TOUT l'espace** : 105/105, jamais égal, jamais
   sous-additif ; écarts {+1 : 21, +2 : 42, +3 : 33, +4 : 8, +5 : 1}.
   Le coût de deux sous-instances sélectionnées ne se partage jamais à
   cette échelle — c'est exactement la propriété dont une totalisation a
   besoin, et son échec aurait tué le schéma (test de plafond).
2. **⊕ n'est jamais sous-additif** (78 exactement additifs, 27 super,
   écarts ≤ +2) ; sur la famille NOR, la super-additivité croît
   (A-013 re-vérifié par DEUX méthodes indépendantes : 6 en force brute,
   14 au solveur — écarts +2, +8).
3. **∧ et ∨ PARTAGENT du coût** (21/105 sous-additifs chacun — témoin :
   deux fonctions-point fusionnent, 3 < 4). Comptes ∧/∨ identiques =
   vérification interne exacte (dualité par complément, W(¬f) = W(f)).
   Conséquence de construction : la colle d'un gadget de totalisation doit
   être de type sélecteur/⊕, PAS de type ∧/∨.
4. MUX domine strictement ⊕ : W(MUX) − W(⊕) ∈ {+1, +2, +3} sur les 105
   paires. Curiosité consignée sans suite : MUX(NOR₃,NOR₃) = 14 =
   NOR₃⊕NOR₃.
