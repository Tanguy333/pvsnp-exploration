# T26-S2 — THÉORÈME (prouvé, tout k) : la borne k(k+1) dans la sous-classe isotypique — le premier énoncé asymptotique de borne inférieure ∀k du fil

- **Exécutée le** : 2026-07-24
- **Script** : [`checks/task_t26s2_isotypique.py`](../../checks/task_t26s2_isotypique.py)

## LE THÉORÈME

> **Pour tout k ≥ 3 et tout seuil 2 ≤ t ≤ k−1** : tout séparateur
> décomposable ISOTYPIQUE (k blocs identiques (a, b, M), 1 ≤ a ≤ b,
> a+b ≤ M) de MAJ_k^t(OR2^k) vérifie **M ≥ k+1**, donc
> **W = kM ≥ k(k+1)**. Le témoin mod-k (a,b,c) = (1,1,k−1) l'atteint :
> la borne est EXACTE dans cette classe.

## Preuve (complète)

**Restriction {a, M}** : les états n'utilisant que les valeurs a et M
par bloc sont un sous-ensemble des états du système — toute collision
de la restriction est une collision du système complet. Sommes :
s(m, γ) = m·a + γ·(M−a), 0 ≤ γ ≤ m ≤ k (γ = nombre de blocs au
sommet). Il suffit d'exhiber une collision (m₁ ≥ t > m₀, s égaux)
dès que M ≤ k.

**Cas 1 : a ≤ t−1 et M ≤ k.** Prendre γ₁ = 0, γ₀ = a,
Δ := m₁ − m₀ = M − a (alors Δ·a = γ₀·(M−a) : sommes égales), et
m₀ = min(t−1, k−M+a) :
- si k−M+a ≥ t−1 : m₀ = t−1 ≥ a ✓ ; m₁ = t−1+M−a ∈ [t, k] ✓ ;
- sinon : m₀ = k−M+a ≥ a (car M ≤ k) ✓, m₀ < t ✓, m₁ = k ≥ t ✓
  (t ≤ k−1).
γ₀ = a ≤ m₀ ✓ dans les deux sous-cas. Collision ⟹ infaisable ⟹
M ≥ k+1.

**Cas 2 : a ≥ t, k impair** (t = (k+1)/2) : M ≥ a+b ≥ 2a ≥ 2t = k+1
directement.

**Cas 3 : a ≥ t, k pair** (t = k/2) : M ≥ 2a ≥ k ; si M = k, alors
a+b ≤ M = 2t et a ≥ t forcent a = b = t, d'où s = t·(m+γ) et la
collision (m₁, γ₁) = (t, 0) contre (m₀, γ₀) = (t−1, 1) (γ₀ ≤ m₀ ⟺
t ≥ 2 ✓). Donc M ≥ k+1. ∎

## Vérification mécanique

k = 3..10 : énumération de TOUS les blocs isotypiques avec M ≤ k —
**zéro séparable** (8/8), témoin (1,1,k−1) séparable à M = k+1 (8/8).

## État combiné de la borne décomposable après S1 + S2

| classe | résultat | statut |
|---|---|---|
| décomposable GÉNÉRALE, k = 3..8 | = k(k+1) | exhaustif (T26-S1) |
| décomposable ISOTYPIQUE, tout k, 2 ≤ t ≤ k−1 | ≥ k(k+1), exact | **THÉORÈME (cette tâche)** |
| décomposable générale, k ≥ 9 | conjecturé k(k+1) | ouvert (les optima k ≤ 8 sont tous isotypiques) |
| décomposable ⇒ global | vrai à k = 3, 4 | ouvert — l'autre moitié (Tour 27 candidat) |

Bornes du domaine consignées : t = 1 (OR externe) donne 2k, t = k
(AND externe) échappe aussi — la loi est propre au comptage
2 ≤ t ≤ k−1, cohérent avec le lemme du comptage (F-018).

## Portée honnête

Premier énoncé de borne inférieure asymptotique prouvé POUR TOUT k du
fil : Ω(k²) dans la sous-classe isotypique-décomposable. Deux
réductions restent avant l'écho jouet complet (isotypique → général
décomposable ; décomposable → global) — chacune vraie sur tous les
points vérifiés, aucune prouvée. Échelle jouet, zéro implication
P vs NP directe — mais la moitié inférieure de l'écho du mur TC⁰ a
maintenant un théorème là où il y a trois jours il n'y avait rien.
