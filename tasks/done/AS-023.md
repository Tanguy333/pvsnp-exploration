## 1. Pourquoi b_d — le chemin de la preuve

b_d := D(2d+1, d, d+1) est la base du théorème AS-022 (C13 pour
d = O(log n)), qui n'utilise que b_d ≥ 1/2^{d+3}. Mesuré (AS-022) :
b_d = 5/32, 1/8, 93/512, 59/128, 13/32, 1/8 pour d = 2..7 — jamais sous
1/8. Cible : la loi **b_d ≥ 1/8 pour tout d, égalité ssi d Mersenne**.

## 2. L'instrument : test de vide + LLL exacte (10⁷× moins de nœuds)

Deux insights d'ingénierie, chacun imposé par un échec :
- **Test de vide** : pour la loi, la VALEUR de b_d est inutile — il
  suffit d'énumérer sous le rayon 1/8(1+ε) : vide ⟹ b_d > 1/8 certifié ;
  point à 1/8 ⟹ égalité certifiée ; point sous 1/8 ⟹ loi réfutée.
  (La valeur exacte de b_8, elle, plafonne à 2·10⁸ nœuds même rayonnée
  par une borne sup serrée — abandonnée, non nécessaire.)
- **LLL exacte sur Gram** (rationnels partout, float seulement dans les
  bornes du parcours ; la version flottante crashait à d=13, Gram non
  définie-positive à conditionnement > 10¹⁶) : les arbres passent de
  3·10⁸ nœuds (cap, non conclu) à **1..19 nœuds**.
  Validation : 6/6 sur d = 2..7 (vides et non-vides conformes aux
  valeurs exactes connues).

## 4. Théorème structurel : le diagonal est un CVP parité×polynôme

À n = 2d+1, le complément B-orthogonal de V_d est EXACTEMENT
parité × {polynômes de degré ≤ d} : les dimensions coïncident (d+1) et
l'orthogonalité est l'identité des différences finies
Σ_k (−1)^k C(n,k) p(k) = 0 pour deg p < n. Donc tout résidu est de la
forme (−1)^k·q(k), et **b_d = un CVP explicite en dimension d+1 dans
les coordonnées parité-polynômes** — la reformulation dont une preuve
uniforme a besoin.
