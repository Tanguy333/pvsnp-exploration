# PR-013 — Prompt Proposeur v4.4 : la candidature par théorème de transfert (mécanisme M, sous-but G, transfert T prouvé, statut S), dans les deux directions

`Rattachement :` Instrument pour l'Atlas entier — le générateur de
candidatures, réorganisé autour du mécanisme de transfert (ordre
utilisateur 2026-09-12 : « un prompt pour le proposeur incluant le
nouveau mécanisme sous-but G ⟹ P = NP »).
**Relu à la clôture : la cellule visée a-t-elle bougé ? OUI, en
instrument** — le prompt ne demande plus une « famille » mais le
quadruplet (M, G, T, S) ; les quatre entrées du registre y deviennent
les quatre façons d'échouer (pas de T ; T hors cible ; G emprunté ;
G réfuté ou miroir) ; la ligne 7 y est le modèle explicite des deux
directions ; le champ 3 porte les six étiquettes de maillon (PROUVÉE,
OUVERT POUR LE MÉCANISME, OUVERTE PAR EMPRUNT, MIROIR, EXCLUE,
ABSENTE) ; le champ 4 devient le test de G (énoncé structuré, statut,
atteinte par M, sens unique de T). Fichier :
`prompts/proposeur_front_neuf.md` (v4.4, révisé en place — nom sacré).

`Test de plafond :` tâche d'écriture ; jugée à la neuvième candidature.

## Ce qui change de v4.3 à v4.4

1. **§1 mission** : le quadruplet (M, G, T, S) ; la ligne 7 comme modèle
   des deux directions (CW19 Thm 8 : transfert prouvé, algorithme
   ouvert, sens unique) ; la règle du 2026-09-12 énoncée pour P = NP ;
   trois issues admises (famille explorable, ligne documentaire, entrée
   de registre).
2. **§2 exclusions** : la lecture algorithmique du verrou Frege/EF
   réservée (item 15) ; la ligne 19 décrite par son transfert
   (dichotomies) ; bloc « Éliminées — au registre » E-1 à E-4.
3. **§2 bis** : état au 2026-09-12 (registre, sept mécanismes, les trois
   règles).
4. **§2 ter** : les huit candidatures relues par le transfert, en une
   entrée chacune.
5. **§2 quater, nouveau** : le schéma de transfert défini ; le modèle
   ligne 7 déplié ; les quatre échecs mappés sur E-1..E-4 avec leur
   symptôme et leur test (test de l'emprunt : « si les lignes voisines
   fermaient leur verrou, G serait-il fermé sans M ? ») ; ce qu'est un
   bon G (structuré, T à sens unique), les deux bons G réfutés, le seul
   G ouvert connu (réservé) ; le miroir illustré par Håstad 2001.
6. **§3** : les barrières pour une famille algorithmique (sans objet
   structurel + verrou réel).
7. **§4** : champ 1 = G ; champ 3 = le transfert avec les six
   étiquettes ; champ 4 = le test de G en quatre lignes ; champ 5 :
   plafond atelier étendu aux solveurs SAT (~10⁷ conflits) ; champ 6 :
   folklore-check sur le statut de G ; champ 9 : les sept mécanismes
   transversaux listés.
8. **§5** : régime 8 (G miroir ou emprunté) ; régime 7 reformulé (pas de
   T / T hors cible).
9. **§6** : format adapté (G, T avec numéro, test de l'emprunt, témoin
   exécutable pour une entrée de registre).

## Réserves

- Non testé : jugé à la prochaine candidature.
- Aucune direction suggérée (règle 1) ; le prompt nomme ce qui est
  réservé (ligne 15) et ce qui est réfuté, pas ce qu'il faut chercher.
- Håstad 2001 (« 7/8 + ε NP-dur ») cité de mémoire comme exemple de
  miroir — classique ; à vérifier sur texte si une candidature s'en
  sert.
