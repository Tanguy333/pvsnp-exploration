## 1. Cadre

Cœur (1, b, 0, o), b ≥ 2 : u = {x₁}, v = B, O le dehors. En branche
tous-légers-μ=0 de l'induction MC-011 (tous les l ∈ O ont ω_l = 1, aucun
monôme multi-extérieur), chaque léger porte exactement son singleton
(Lemme MC-011 §1), donc pour tout w ⊆ {x₁}∪B et L ⊆ O :
p(w ∪ L) = p_AB(w) + |L|, et W = W_AB + o, où p_AB est la restriction de
p au cube {x₁}∪B. Notons c := p(u) = a_{{x₁}}, P := p(v) = W_B (poids
pur-B), X := poids mixte du cube, W_AB = c + W_B + X.

**Les bandes.** Tout zéro du cube, décalé par L, reste un zéro :
p_AB(w) + t ∉ {c, P} pour 0 ≤ t ≤ o — c'est-à-dire : les zéros du cube
évitent les DEUX BANDES [c − o, c] et [P − o, P].

## 2. LEMME (la branche tous-légers paie) — W_AB ≥ b + 2o + 1 pour o ≥ 1

Quatre forçages, tous par les bandes :
1. **c ≥ o + 1 et P ≥ o + 1** : le zéro ∅ vaut 0, qui doit éviter les
   deux bandes — 0 ∉ [c−o, c] force c > o, idem P.
2. **E_j := a_{{j}} + a_{{x₁,j}} ≥ 1** pour tout j ∈ B : le zéro
   {x₁, j} vaut c + E_j ∉ [c−o, c], donc E_j ≥ 1 ; les familles étant
   disjointes, σ_B + X ≥ Σ_j E_j ≥ b (σ_B := Σ a_{{j}}, et seules les
   paires {x₁, j} du mixte comptent).
3. **D_j := Σ{a_S : j ∈ S ⊆ B} ≥ o + 1** pour tout j : le zéro B∖{j}
   vaut P − D_j ∉ [P−o, P].
4. **Convexité (MC-010)** : Σ_j D_j = Σ_{S⊆B} |S| a_S ≤ σ_B + b(W_B −
   σ_B), d'où W_B ≥ (o+1) + σ_B(1 − 1/b).

Assemblage : si σ_B ≤ b,
W_AB = c + W_B + X ≥ (o+1) + [(o+1) + σ_B(1−1/b)] + (b − σ_B)
     = b + 2o + 2 − σ_B/b ≥ b + 2o + 1 ;
si σ_B ≥ b + 1, W_AB ≥ 2(o+1) + σ_B(1−1/b) > b + 2o + 1. ∎
*(Le solveur mesure le minimum réel des séparateurs-à-bandes à
b + 2 + 2o — la bande de largeur o+1 simule exactement le dehors ; notre
borne b + 2o + 1 est en dessous, et la borne REQUISE b + o + 2 loin en
dessous : marge partout.)*

## 3. THÉORÈME — F(1, b, 0, o) = b + 2 + 2o pour tous b ≥ 2, o

Majorant : la construction linéaire (MC-009 §4). Minorant, par
l'induction MC-011 — **[précision VER-MC-2 : la trichotomie est
EXISTENTIELLE — il suffit d'UN extérieur en branche 1 ou 2 pour
descendre ; « tous-légers-μ=0 » est le cas restant, et son exhaustivité
repose sur ω_l ≥ 1 pour tout l, vrai par le préambule du Lemme MC-011
§1]** : au niveau o, s'il existe un extérieur lourd (branche 1) ou léger
à μ_l ≥ 1 (branche 2), la restriction x_l := 0 perd ≥ 2 et la récurrence
descend — sinon la branche tous-légers-μ=0 s'applique au niveau o′ ≤ o
atteint. Si la descente atteint o′ = 0 :
W ≥ 2o + (b + 2) (base MC-012). Si elle s'arrête en branche 3 à o′ ≥ 1 :
W ≥ 2(o − o′) + W_AB(o′) + o′ ≥ 2(o − o′) + (b + 2o′ + 1) + o′
  = b + 2o + (o′ + 1) ≥ b + 2 + 2o. ∎

**Corollaire (réduction M).** F(1, b, m, o) = b + 2 + 2o pour tout m. La
branche linéaire est close sur tous ses paramètres — troisième famille de
fibres-points entièrement démontrée, après la comparable (MC-011) et
(1,1) (MC-011).
