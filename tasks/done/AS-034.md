## 1. La route

Pour le CVP val(z) = (b+2z)ᵀQ(b+2z) : Θ_t(s) = Σ_z e^{−π·val(z)/s²}
donne **minval ≥ (s²/π)·ln(1/Θ_t(s))** pour tout s — et par Poisson,
Θ_t se réécrit sur le réseau dual avec des phases e^{iπ m·Cf} qui,
chez nous, sont les **signes de Lucas** (AS-024). C13 devient une
estimée d'annulation d'une série thêta à signes de Lucas — un objet
analytique unique, sans jauge de découpage (l'obstruction n°1
d'AS-033 ne s'applique pas), sans perte par niveau (l'obstruction
d'AS-029 non plus).

Le 94,5 % uniforme est l'artefact de la grille (s² = vrai/4 :
perte = ln(2)/4π-type) — la borne tend vers 100 % quand s → 0 :
**l'outil est asymptotiquement exact**, aucune perte composable.
Honnêteté : cette exactitude à s → 0 est TRIVIALE (la thêta dégénère
sur le minimum) ; le contenu d'une preuve est le contrôle de Θ à s
MODÉRÉ, là où la série duale converge — c'est là que vit l'analyse.
