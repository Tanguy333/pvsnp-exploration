## 1. Le moteur symétrique (V-049b)

`svp_sym.sym_shortest(d, n)` énumère les sous-réseaux L⁺ (palindromes) et
L⁻ (antipalindromes), de rang **r/2 chacun**, au lieu du plein rang r.
Base de L± = **noyau entier saturé de (S∓I)** (S = σ en coords de L),
construit exactement (sympy) — jamais le système générateur naïf (dont
l'indice 1 est vérifié sur 4 cellules mais non prouvé général).

**Garantie** : min(λ⁺, λ⁻) = plus court vecteur AUTO-SYMÉTRIQUE = borne
sup de λ₁(L), égale ssi le minimum global est symétrique. **Conditionnel
au secteur symétrique** — JAMAIS un certificat inconditionnel (les
vecteurs asymétriques sont hors L⁺ ∪ L⁻ ; ≈20e auto-correction : ma
revendication initiale « (2) inconditionnel » était fausse).

**Tests d'acceptation** :
- cohérence 4/4 : min(λ⁺,λ⁻) = min connu à (7,50)=16, (9,72)=24,
  (10,146)=28, (11,136)=28 ; secteur conforme au Lemme A ;
- vitesse : **(10,146) 163,5 s plein → 2,3 s sym = ×70** (rang 136→68).

## 2. La courbe de décroissance (d = 10, d = 12)

Scan n = plancher..150 (pas 2), 129 cellules, **106 s** au moteur sym.
Profil en deux phases :

| | d = 10 (m=11) | d = 12 (m=13) |
|---|---|---|
| plancher 2(d+1) | 22 | 26 |
| phase algébrique | n=22→76, 1908→42 | n=24→110, 9360→54 |
| bascule PTE (1er plat) | **n=78** (min 38) | **n=112** (min 50) |
| plateau plat final | 28 dès n=98 | 44 dès n=130 |

Lecture : descente algébrique rapide par grands sauts (empilements
cyclotomiques) → frontière franche → palier PTE plat. Le minimum se
**fige avant le plancher** (28 ≠ 22 ; 44 ≠ 26) : ce sont les barreaux
orphelins — les idéales qui réaliseraient le plancher vivent à span bien
plus grand (28 de d=10 = non-existence du fantôme taille 11 sous ce span).
Données : `checks/v050_decay.csv`. Visualisé (échelle log, coloré par phase).

**Portée en temps acceptable : n ≈ 240-260** (< 10 s jusqu'à 200, ~34 s à
240) ; **mur dur vers n ≈ 270-280** (MÉMOIRE, pas temps — noyau sympy
~270×270 rationnel + tampon d'énum saturent la RAM avant le CPU). Le
moteur symétrique DOUBLE la portée vs plein (146 → ~260), confirmant le
×2-sur-span par la mesure.

Donnée : min = 28 jusqu'à n = 240 (secteur symétrique) — le barreau du
fantôme taille 11 ne décroche pas, conditionnellement à la symétrie, sur
ce span étendu.

**Optimisation future** (si pousser d=10 vers n=350-400) : remplacer le
noyau sympy par un HNF entier numpy + streamer le tampon d'énumération —
le mur est mémoire, le CPU a de la marge (34 s seulement à n=240).
