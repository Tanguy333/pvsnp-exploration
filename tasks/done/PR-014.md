## Les prises (résumé du dossier)

1. **Th. 8 / Th. 9 confondus** : apprentissage ⟺ distingueurs à erreur
   BORNÉE (Th. 8) ; preuves P-naturelles ⟺ distingueurs SANS erreur
   (Th. 9) ; le pont est CIKK Th. 1.1 (naturel ⟹ apprentissage, UN
   sens). « G est une propriété naturelle par théorème » se lit :
   équivalent à un distingueur à erreur bornée, impliqué par toute
   preuve naturelle, équivalent à une propriété constructive utile à la
   densité près (Williams). Le statut à trois étages tient.
2. **Exclusion crypto sous réserves** : OS17 Th. 2 « *requires
   non-uniformity, and is established only in the exponential security
   regime* » — PRF sûres contre des circuits sous-exponentiels, apprenant
   non uniforme ; Kearns-Valiant couvre l'apprenant polynomial. Tient,
   qualifiée.
3. **Cellule discriminante vide par déséquilibre (mesuré)** : MOD₆ = 1
   sur 29/256 points à n = 8 ; le constant 0 atteint 227/256 ≥ 7/8 :
   adeg_{F,1/8}(MOD₆) = 0 sur F₂ et F₃ — « ≥ 3 » faux tel qu'écrit. Un
   seuil d'accord ε n'a de sens que si ε < biais. Correction ε = 1/16 :
   constant insuffisant, aucun polynôme ≤ 4 trouvé n'atteint 240 sur F₂
   (235), sans certificat ; run ciblé en cours. Le régime de contrôle
   (n = 12 : trois îles, MOD₆ hors de toutes ; n = 8 : PARITY/F₂ = 1,
   MOD₃/F₃ = 2) est conforme. Rien de l'entrée n'en dépend.
4. **La pièce utile** : le mécanisme (9) — Williams Th. 1.2 (« *two of
   the three conditions* ») contre OS17 Th. 8 (apprendre = distinguer
   de l'aléatoire, la densité est dans G) : la raison structurelle de
   l'exception de la ligne 7, généralisant D-005.
