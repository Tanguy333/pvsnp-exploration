## 2. THÉORÈME (loi G) — prouvé

**W([w = u]) = ν − |u| + 1 si u ≠ 0 ; ν si u = 0.**

*Majorant.* Pour u ≠ 0 : p := m_u + Σ_{j ∉ u} m_{u∪{j}} (poids
ν − |u| + 1). Valeurs : p(u) = 1 (seul m_u actif) ; p(w) ≥ 2 pour
w ⊋ u (m_u et au moins un m_{u∪{j}}) ; p(w) = 0 pour w ⊉ u. Ensembles
{1} et {0, ≥2} disjoints. Pour u = 0 : p := Σ_j y_j (poids ν), valeurs
{0} contre {≥ 1}.

*Minorant (packing — Lemme 4 de MC-001).* Les paires (u∪{j}, u), j ∉ u,
ont f(u∪{j}) = 0 ≠ 1 = f(u), supp(u) ⊊ supp(u∪{j}), et des
ensembles-différences D_j = {S ⊆ u∪{j} : j ∈ S} deux à deux disjoints
(un S commun à D_j et D_{j'} devrait contenir j et j' tout en étant
⊆ u∪{j}). Cela force W ≥ ν − |u|. Si u ≠ 0, la paire (u, v) pour
n'importe quel v ⊊ u ajoute D = {S ⊆ u : S ⊄ v}, disjoint de tous les
D_j (ses éléments sont ⊆ u, les leurs contiennent j ∉ u) : W ≥ ν−|u|+1. ∎

*(Première application POSITIVE du packing depuis sa saturation en
MC-003 : aveugle sur les antichaînes, il est exact sur les points.)*

## 3. THÉORÈME (loi F, cas recouvrement) — prouvé

**Pour v = u ∪ {j*} (b = 1, a = 0, m = |u|) :
F = ν − m si m ≥ 1 ; ν − 1 si m = 0.**

*Majorant.* m ≥ 1 : p := m_u + Σ_{j ∉ u, j ≠ j*} m_{u∪{j}} (poids
ν − m) : p(u) = p(v) = 1 (à v, seul m_u est actif — u∪{j} ⊄ v pour
j ≠ j*) ; tout autre sur-ensemble de u contient un j ∉ u, j ≠ j* :
valeur ≥ 2 ; le reste : 0. m = 0 (u = 0, v = {j*}) : p := Σ_{j ≠ j*} y_j
(poids ν − 1) : les deux uns valent 0, tout zéro contient un bit ≠ j*.

*Minorant.* Paires de packing (u∪{j}, u) pour j ∉ u, j ≠ j* (les
ν − m − 1 D_j disjoints comme en §2), plus, si m ≥ 1, la paire (u, v')
avec v' ⊊ u. ∎

## 5. Le corollaire — et la CORRECTION de MC-007

Des lois (G prouvée ; F au statut de C-MC008 hors recouvrement), pour les
fibres-points à base 1 bit (g := W(h) − G(c₀) − G(c₁)) :

- c₁ ⊊ c₀, c₁ ≠ 0 : ~~g = |c₀\c₁| − 2~~ **[CORRIGÉ par VER-MC-1,
  2026-08-07 : la formule vraie est g = d − max(d, 2), d = |c₀\c₁| —
  soit −1 au recouvrement (d = 1) et 0 dès d ≥ 2 ; « d − 2 » coïncide
  sur le domaine mesuré s = 3 (d ≤ 2) mais est fausse dès d ≥ 3,
  contre-exemple vérifié à s = 4 : (1111, 0001) → g = 0 ≠ 1]** — le
  partage n'existe qu'au RECOUVREMENT (d = 1, g = −1) ; l'emboîtement
  profond ne partage pas (g ≥ 0) — la caractérisation du SIGNE est
  inchangée ;
- c₀ ⊊ c₁ : g = 0 ; c₁ = 0 : g ≥ 0 ;
- incomparables (k₀ = |c₀\c₁|, k₁ = |c₁\c₀| ≥ 1) :
  g = k₀ + k₁ − max(2, k₀, k₁ + 1) **≥ 0 toujours**.

**Correction consignée** : la règle de MC-007 (« g < 0 ⟺ supp(c₁) ⊊
