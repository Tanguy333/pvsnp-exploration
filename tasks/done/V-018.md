## L'énoncé réfuté

> « *Conjecture 5. Consider the basis B for any n, d. There exists a
> vector γ ∈ L(B) with the smallest ℓ₂ norm such that γ_n = 1.* »
> — Krishan-Vishwanathan, ECCC TR24-074 (2024), lu visuellement p. 17.

## Le contre-exemple : (d = 21, n = 30)

L'unique plus court vecteur (au signe près) du réseau est le
**palindrome** de norme² = 517 673 216 :

```
v = [-2, 31, -215, 864, -2143, 3053, -1172, -4336, 8864, -6017,
     -1969, 4448, 1159, -3211, -4522, 10336, -4522, -3211, 1159,
     4448, -1969, -6017, 8864, -4336, -1172, 3053, -2143, 864,
     -215, 31, -2]
```

avec **γ₃₀ = −2** : aucun plus court vecteur n'a γ_n = ±1.

## La pile de vérification (5 couches)

1. Détection par SVP flottant (V-017b) — 13 cellules suspectes, d = 21..29 ;
2. **SVP exact en rationnels purs** (Gram-Schmidt + Fincke-Pohst en
   Fractions, zéro flottant ; 3 témoins sains passent, les 13 suspects
   échouent) — bug de ma première version détecté par les témoins et
   corrigé (borne d'énumération) ;
3. Appartenance au réseau vérifiée **symboliquement** (sympy :
   (1−x)²² divise v) ;
4. **Énumération contrainte indépendante** (base stencil brute non
   réduite, code distinct) : aucun vecteur à γ_n = ±1 de norme
   ≤ 517 673 216 — le minimum contraint est strictement plus grand ;
5. Énoncé original relu visuellement dans le PDF (p. 16-17) : « for
   any n, d » — la cellule est dans le périmètre.

12 autres cellules réfutantes confirmées en exact (couche 2) :
d = 22..29, premiers échecs à n−d = 6 et 9.

## PORTÉE — la nuance essentielle

**La conjecture telle qu'énoncée est fausse ; le programme de KV n'est
pas mort.** Le régime utile à leur application ACC (d petit devant n)
n'est pas touché : nos ~290 cellules à d ≤ 16 (fenêtres larges) la
soutiennent toutes. Le bon énoncé exige une hypothèse n ≥ f(d) ; nos
données situent la frontière (échecs dès n−d ≤ 9 pour d ≥ 21). C'est
une **information utile aux auteurs** : leur conjecture doit être
restreinte, et nous savons où.

## Addendum (vérification utilisateur) — troisième voie indépendante

Vérification DIRECTE par sommes de puissances multi-ensembles (sans
polynômes ni réseau) : les sommes Σ_A i^k et Σ_B i^k coïncident pour
**k = 0..17** (entiers jusqu'à 27 chiffres) et **diffèrent à k = 18**
(écart 15 673 010 831 622 144 000) — le palindrome est divisible par
(x−1)¹⁸ exactement, pas (x−1)¹⁹ : degré PTE 17 pile. Trois chemins
disjoints confirment désormais l'appartenance : stencils du réseau,
division symbolique sympy, moments bruts.
