## [A] Le mur symétrique mesuré (réplication BHLR)

| n | d\* (ε ≤ 1/8) | d\* (ε ≤ 1/(2n)) |
|---|---|---|
| 8 | 3 | 4 |
| 12 | 4 | 5 |
| 16 | 5 | 8 |
| 20 | 7 | 11 |

Croissance **≈ linéaire en n** (≈ n/3 pour ε fixe, ≈ n/2 pour ε ~ 1/n) —
MAJ résiste fortement aux polynômes toriques symétriques, courbes ε\*(d)
complètes consignées dans la sortie du script. C'est la réplication
numérique du théorème symétrique de BHLR.

## [B] Le contraste structurel (la trouvaille)

À n = 3, 4 : **ε\*(général) = ε\*(symétrique) exactement, à tous les
degrés** — l'asymétrie n'aide pas sur le tore.

> Contraste avec le fil F-011 : dans le modèle **faible mod 6**,
> l'asymétrie *battait* l'anomalie au même n = 4 (étape 17, signature de
> K₄). Le modèle **torique** semble robuste à l'asymétrie aux petites
> tailles — exactement la propriété qu'il faut à un « Pas-1 composite »
> pour ne pas s'effondrer comme le modèle faible (notre conclusion
> d'étape 19). Cohérent avec le choix de BHLR d'en faire le véhicule de
> la conjecture MAJ ∉ ACC⁰.

*(Réserve : n ≤ 4 est minuscule ; la symétrisation WLOG sur le tore n'est
pas prouvée à notre connaissance — c'est précisément pourquoi le cas
général de BHLR reste ouvert.)*
