# TÂCHE F-003 : poids SYM∘AND d'IP — ✅ COMPLÉTÉE en **correction de cadrage**

- **Type** : F (mesure + correction interne)
- **Exécutée le** : 2026-06-09
- **Script** : [`checks/task_f003_symand_ip.py`](../../checks/task_f003_symand_ip.py)

## Résultat de mesure

Poids minimal d'une représentation SYM∘AND de IP_{2k} (monômes positifs à
coefficients entiers ≥ 0, g quelconque ; condition exacte : ensembles de
valeurs disjoints sur IP⁻¹(1)/IP⁻¹(0)) — ILP à indicateurs de paires :

| k | poids min | statut |
|---|---|---|
| 2 | **2** | Optimal |
| 3 | **3** | Optimal |

La construction triviale `p = Σ x_iy_i`, `g = (· mod 2)` — c'est-à-dire
**IP = PARITY_k ∘ AND₂, un circuit SYM∘AND par définition** — est optimale.

## La correction de cadrage (le vrai livrable)

La tâche F-003 du backlog était formulée comme « quantifier le verrou
Williams→TC⁰ dans le bon format [SYM∘AND] » en mesurant IP. **Ce cadrage
était erroné**, hérité d'un glissement dans la conclusion de F-001 :

1. **IP est linéaire en SYM∘AND** (= k, prouvé optimal ci-dessus). Il ne
   témoigne d'aucun obstacle dans ce format.
2. **Ce dont IP témoigne** (F-001, T-F006) : la weight L1 des
   représentations *à seuil* (PTF) — une mesure différente, où IP est
   exponentiel ((3^k−1)/2).
3. **Le vrai verrou Williams→TC⁰** : Beigel-Tarui transforme tout circuit
   ACC en SYM∘AND quasi-polynomial. L'analogue pour TC⁰ devrait transformer
   les portes **THR à poids non bornés** — et les objets-frontière sont les
   fonctions **THR∘THR**, pas IP. (Williams 2014 a d'ailleurs étendu sa
   méthode à ACC∘THR ; le mur est THR∘THR.)

**Leçon de discipline** : c'est la 2e fois qu'une mesure du dépôt risque
d'être interprétée dans le mauvais format (q.13 : magnitude L∞ vs weight
L1 ; ici : weight PTF vs taille SYM∘AND). Toute mesure doit nommer
exactement le modèle de calcul auquel elle borne quelque chose.

## Reformulation (F-003′, candidate au backlog)

Mesurer le poids SYM∘AND minimal de petites fonctions **THR∘THR à poids**
(n = 4..6, 2 étages de seuils pondérés) — les vrais objets-frontière. Si
même à n=6 certaines THR∘THR exigent un poids SYM∘AND >> poly, c'est la
quantification empirique du mur ; si toutes restent petites, c'est un
indice (faible) que la transformation existe.
