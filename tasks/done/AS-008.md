## 1. Énoncé

Pour w ∈ Z, soit THR_w(x) = [|x| ≥ w] sur {0,1}ⁿ, V_d = polynômes
multilinéaires réels de degré ≤ d, et

  D(n, d, w) = min_{Z ∈ Z^{2ⁿ}} ‖(Z + THR_w/2) − proj_{V_d}‖²₂
             = min_Z ‖P(n,d)(Z + THR_w/2)‖²   (la quantité de KV).

**Lemme (padding, AS-004 — prouvé).** Pour tout n, d, t :
D(n+2, d, t) ≥ D(n, d, t) + 2·D(n, d, t−1) + D(n, d, t−2).

*Preuve.* Fixer deux variables ; tout témoin (Z, p) de niveau n+2 se
restreint sur chacune des 4 fibres (a,b) ∈ {0,1}² en un témoin de
THR_{t−a−b} sur n variables (un polynôme de degré ≤ d restreint reste de
degré ≤ d ; Z restreint est entier) ; la norme² se décompose en somme des
fibres ; chaque fibre ≥ son minimum libre. ∎

**Itération.** (1,2,1)^{∗k} = (C(2k, s))_s, donc pour n = n₀ + 2k :
D(n, d, t) ≥ Σ_w C(2k, t−w) · D(n₀, d, w).

**Base certifiée (n₀ = 5, full-space, énumération complète + vérification
exacte — AS-004).** S_d := Σ_{w=1}^{5} D(5, d, w) :
S₁ = 35/16, S₂ = 31/32, S₃ = 3/16 — strictement positifs.

**Théorème.** Pour d ∈ {1, 2, 3} et tout n impair ≥ 11, au seuil central
t = (n+1)/2 (f = MAJ_n), avec k = (n−5)/2 :

  D(n, d, t) ≥ S_d · C(2k, k+2) ≥ S_d · 4^k/(8√k)

d'où  **dist = √D ≥ (√S_d/16) · 2^{n/2}/n^{1/4}**.

*Preuve.* Les offsets t−w, w ∈ {1..5}, valent k + j avec |j| ≤ 2 ;
C(2k, k+j) ≥ C(2k, k+2) (unimodalité) ; C(2k, k+2)/C(2k, k) =
k(k−1)/((k+1)(k+2)) ≥ 1/4 pour k ≥ 3 ; C(2k, k) ≥ 4^k/(2√k). ∎

**Corollaire.** La Conjecture 13 (qui autorise une perte n^{O(1)} ;
n^{1/4} ⊂ n^{O(1)}) est **vraie pour tout degré constant d ≤ 3** — et la
méthode s'étend à tout d fixé modulo une base certifiée S_d(n₀) > 0.
