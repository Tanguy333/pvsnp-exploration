## Ce qui a été fait

1. **La grille** (`checks/hol004_seize_vertex.py`) : réductibilité
   (minors des 7 bipartitions), symétrie, **Z-réel (Shao-Cai)**, zones
   K (huit-vertex, HW≥/≤, single-weighted, vanishing — via K̃⁻¹⊗⁴
   exact), A directe (support affine + i^Q, Q quadratique à croisés
   pairs, énumération mod 4), P (partitions + signes + rang-1
   itératif), M (parité + MGI d'arité 4, FCST Lemma 2.24), L (16
   tests A-shiftés, exposants α mod 8).
2. **LA PRISE, corrigée en cours de tâche et MARQUÉE** : le premier
   scan rendait 48 962 « COIN » sur les 0/1 — tous réels, donc fermés
   par Shao-Cai : le coin exige le complexe. Zone Z-réel ajoutée ; le
   taux anormal (74,7 %) a servi d'alarme ; commentaire de prise dans
   le script, section dédiée dans le data.
3. **Contrôles validés** : 0/1 exhaustif → 62 906 Z-réel + 2 601
   réductibles + 28 symétriques + 1 nulle = 65 536, ZÉRO COIN ;
   0/±1 idem.
4. **La chasse complexe** : 8 000 aléatoires {0, ±1, ±i} (COIN 7 707 —
   le générique est hors classes directes) ; scan STRUCTURÉ exhaustif
   (supports de taille 3, valeurs {1, i} : 3 920 signatures) →
   **1 456 épingles reproductibles**, listées par ordre
   lexicographique, première : supp {0000, 0001, 1110}, i sur 0000.
5. Data : `data/hol004_seize_vertex.md` ; calibrations (EQ₄,
   produit, affine-réductible, parité) toutes conformes.

## Réserves

- **Périmètre** : les classes TRANSFORMÉES (A-/P-/L-/M-transformable,
  réel-transformabilité) ne sont pas testées — les épingles sont des
  CANDIDATES, pas des instances certifiées du coin ; HOL-005
  (balayage O₂(ℂ)/GL₂ par Gröbner sur la première épingle) est la
  suite nommée.
- Convention M_Out/M_In de la MGI implémentée telle que citée ;
  calibration sur matchgate explicite à faire si M devient
  discriminant.
- T4-L : 0 détection partout — cohérent avec la délicatesse déclarée
  de L, mais la brique n'a pas de calibration positive (à construire
  depuis un exemple L de CLX si besoin).
- Échantillon aléatoire : graine unique ; le scan structuré est
  exhaustif sur son sous-espace (supports taille 3, motifs {1, i}).
