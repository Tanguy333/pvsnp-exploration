## 1. Cadre

Cœur incomparable au sol : ν = 1 + b, u = {x₁} (a = 1), v = B (|B| = b ≥
2), tout le reste zéro. Pour un séparateur p : c := a_{{x₁}} = p(u) et
P_B := p(v) = W_B (le poids pur-B tout entier s'active en v) ; ∅ est un
zéro de valeur 0, donc c ≥ 1 et W_B ≥ 1. Poids : W = c' + W_B + X où
c' := poids pur-A = c (A = {x₁} n'a qu'un monôme) et X := poids mixte.
Pour j ∈ B : E_j := p(u∪{j}) − p(u) = a_{{j}} + a_{{x₁,j}} — les familles
{S : j ∈ S ⊆ {x₁, j}} sont deux à deux disjointes, et u∪{j} est un zéro,
donc **E_j ≥ 1** ; seuls les singletons de B et les PAIRES {x₁, j}
comptent dans Σ_j E_j ≤ σ_B + X (σ_B := Σ_j a_{{j}}).

## 2. THÉORÈME — F(1, b, 0, 0) = b + 2 (b ≥ 2)

Majorant : la construction linéaire (MC-009 §4, o = 0), poids 2 + b.
**Minorant.** Supposons W ≤ b + 1. Alors
b + 1 ≥ W = c + W_B + X ≥ 1 + σ_B + X ≥ 1 + Σ_j E_j ≥ 1 + b,
d'où ÉGALITÉ partout : **c = 1** ; **W_B = σ_B** (aucun monôme de B de
taille ≥ 2) ; **X = Σ_j a_{{x₁,j}}** (tout le mixte est en paires) ; et
**E_j = 1 pour chaque j**. Maintenant la cascade de collisions : c = 1
est une valeur de un ; pour chaque j, {j} est un zéro (b ≥ 2 ⟹ {j} ≠ v),
donc a_{{j}} = p({j}) ≠ 1 ; avec E_j = a_{{j}} + a_{{x₁,j}} = 1 et des
entiers ≥ 0, il reste (a_{{j}}, a_{{x₁,j}}) = (0, 1) pour tout j. Donc
σ_B = 0, donc P_B = W_B = 0 = p(∅) — un UN partage la valeur du ZÉRO ∅ :
la disjonction est violée. ∎

**Corollaires.** (i) Avec la réduction M (MC-009) :
F(1, b, m, 0) = b + 2 pour tout m. (ii) Avec les branches 1-2 de
l'induction MC-011 (valables pour tout cœur : un extérieur lourd ou un
léger à μ_l ≥ 1 fait perdre ≥ 2 à la restriction x_l := 0) et le majorant
linéaire : **b + 2 + o ≤ F(1, b, 0, o) ≤ b + 2 + 2o** — si la descente
rencontre toujours les branches 1-2, la loi complète suit ; si elle
s'arrête en branche tous-légers-μ=0 au niveau o′, il reste
W ≥ (b + 2) + o′ + 2(o − o′) ≥ b + 2 + o. La fermeture exige l'argument
de bandes de la branche 3 (§4).

## 3. La marche a ≥ 2 — état

La cible est W ≥ a + b + 2 (le plancher couronne, qui vaut la loi pour
a ≥ 2 quand min(2a+b, a+b+2) = a+b+2, et coïncide avec elle à a = 2).
L'analogue du forçage d'égalité y est plus faible : P_A = W_A peut
dépasser 1 et la collision-des-singletons perd sa prise ; la comptabilité
des familles (Σ E_j ≥ b, Σ F_i ≥ a, recouvrement en paires {i,j} compté
deux fois) donne 2W ≥ a + b + W_A + W_B + (2X − X₁A − X₁B), insuffisant
seul. OUVERT — avec certificats solveur (§5) jusqu'à la frontière ν = 8.
