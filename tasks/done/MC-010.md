## 1. Cadre et faits élémentaires (cœur comparable {0-point, B}, b ≥ 2)

p séparateur optimal, P := p(B). Classes de poids : W_B (S ⊆ B), ω_l
(S∩O = {l}), μ (|S∩O| ≥ 2) ; W = W_B + Σ_l ω_l + μ. Un l ∈ O est
**léger** si ω_l = 1, lourd sinon.

- **(F1)** Tout singleton est un zéro et p({i}) = a_{{i}} ≠ p(0) = 0,
  donc a_{{i}} ≥ 1 pour tout i. En particulier s₁ := Σ_{j∈B} a_{{j}} ≥ b,
  et ω_l ≥ a_{{l}} ≥ 1 — **un léger porte exactement son singleton**
  (a_{{l}} = 1 et rien d'autre d'O-part {l}).
- **(F2)** Pour j ∈ B, X_j := B∖{j} est un zéro :
  D_j := P − p(X_j) = Σ{a_S : j ∈ S ⊆ B} ≥ 1.
- **(F3 — copie décalée)** Pour l léger et tout X ⊆ B :
  p(X ∪ {l}) = p(X) + 1 (seul {l} s'ajoute ; les monômes multi-extérieurs
  exigent 2 éléments de O). En X = X_j : p(X_j) + 1 ≠ P ⟹ **D_j ≠ 1**.
- **(F4 — copies multiples, μ = 0)** Si μ = 0 et L ⊆ légers :
  p(X ∪ L) = p(X) + |L|, d'où D_j ∉ {1, …, k} (k := nombre de légers),
  donc **D_j ≥ k + 1** pour tout j.
- **(Convexité)** Σ_j D_j = Σ_{S⊆B} |S|·a_S ≤ s₁ + b·(W_B − s₁). Donc si
  D_j ≥ d pour tout j : W_B ≥ d + s₁(1 − 1/b) ≥ **b + d − 1** (s₁ ≥ b).

## 2. THÉORÈME A (comparable, μ = 0) — W ≥ b + 2o, pour tout o

Si k = 0 : Σω_l ≥ 2o (tous lourds), W ≥ W_B + 2o ≥ b + 2o. Si k ≥ 1 :
(F4) donne D_j ≥ k+1 ∀j, la convexité donne W_B ≥ b + k ; les lourds
donnent Σω_l ≥ 2(o−k) + k = 2o − k ; d'où W ≥ (b+k) + (2o−k) = b + 2o. ∎

## 3. THÉORÈME B (comparable, inconditionnel) — W ≥ b + 2o pour o ≤ 7

Soit k le nombre de légers, d := min_j D_j. (F3) exclut d = 1 quand
k ≥ 1 ; si k = 0 on conclut comme au Théorème A. Trois cas :

1. **d ≥ k + 1** : convexité ⟹ W_B ≥ b + k ; Σω ≥ 2o − k ; W ≥ b + 2o.
2. **2 ≤ d ≤ k, μ en jeu** : soit j* réalisant d. Pour tout L ⊆ légers
   avec |L| = d : p(X_{j*} ∪ L) = p(X_{j*}) + d + μ_L(X_{j*}) ≠ P impose
   **μ_L(X_{j*}) ≥ 1** — chaque d-sous-ensemble de légers doit héberger un
   monôme multi-extérieur (O-part ⊆ L, taille ≥ 2, B-part ⊆ X_{j*}). Un
   monôme d'O-part de taille r ∈ [2, d] couvre C(k−r, d−r) ≤ C(k−2, d−2)
   de ces ensembles, d'où **μ ≥ ⌈C(k,d)/C(k−2,d−2)⌉**. Avec la convexité
   (W_B ≥ b + d − 1) et Σω ≥ 2o − k, il suffit que
   **(d−1) + ⌈C(k,d)/C(k−2,d−2)⌉ ≥ k** — l'inégalité de recouvrement.
3. L'inégalité de recouvrement est vraie pour TOUT 2 ≤ d ≤ k ≤ 7
   (cartographie exhaustive, `data/mc010_minorants.md` §3) ; comme
   k ≤ o, le théorème vaut pour **o ≤ 7**. Premier échec : (k, d) =
   (8, 5) — la zone résiduelle exacte. ∎

**Corollaire (avec MC-009).** Le majorant b + 2o étant construit
(MC-009 §4) et la réduction M prouvée : **F(0, b, m, o) = b + 2o + [m ≥ 1]
est un THÉORÈME pour tout b ≥ 2, tout m, tout o ≤ 7** — et pour tout o si
l'optimum peut être pris sans monômes multi-extérieurs (Théorème A).

## 4. THÉORÈME C (cœur (1,1)) — W ≥ 2 + 2o pour o ≤ 2, et pour tout o si μ = 0

Ici les uns sont {x₁}, {x₂} de valeurs p₁ = a_{{1}}, p₂ = a_{{2}} ≥ 1
(≠ p(0) = 0).

**[Lemme réparateur — VER-MC-1, 2026-08-07.** La preuve initiale
importait de F1 « un léger porte son singleton », or F1 est établi dans
le cadre COMPARABLE (où le 0-point est un un) et ne s'applique pas ici
(le 0-point est un zéro : a_{{l}} = 0 n'y contredit rien directement).
Réparation du vérificateur V2 : les points {1, l} et {2, l} sont des
zéros, donc p({1,l}) = p₁ + a_{{l}} + a_{{1,l}} ≠ p₁ impose
a_{{l}} + a_{{1,l}} ≥ 1, et symétriquement a_{{l}} + a_{{2,l}} ≥ 1 ; si
a_{{l}} = 0, alors ω_l ≥ a_{{1,l}} + a_{{2,l}} ≥ 2, contredisant
ω_l = 1. **Donc un léger porte bien exactement son singleton** —
corroboré sur 440 séparateurs énumérés (33 avec légers, 0 violation).]**

(i) Si k = 0 : W ≥ p₁ + p₂ + Σω ≥ 2 + 2o. (ii) Si k ≥ 1 :
un léger l a a_{{l}} = 1 (lemme ci-dessus), et p({l}) = 1 ∉ {p₁, p₂}
force **p₁, p₂ ≥ 2** ;
d'où W ≥ 4 + (2o − k) ≥ 2 + 2o dès que k ≤ 2 — ce qui couvre o ≤ 2.
(iii) Si μ = 0 et k ≥ 1 : pour L ⊆ légers, p(L) = |L| ∉ {p₁, p₂} force
p₁, p₂ ∉ {1, …, k}, donc p₁, p₂ ≥ k + 1 et
W ≥ 2(k+1) + (2o − k) = 2o + k + 2 ≥ 2 + 2o. ∎
