## Les prises (résumé du dossier)

1. **Périmètre** : le mécanisme (6) borne un algorithme par la preuve
   qu'il produit ; les algorithmes non certifiants (randomisés à erreur
   bornée — Schöning décide, contrairement à ce qu'écrit la
   candidature —, traces Frege/EF, correction hors trace) échappent ;
   le titre « la direction P = NP par les algorithmes SAT » surestime.
2. **Colonne LP/SDP aveugle à la classe** : Rothvoss 2014 (couplage
   parfait ∈ P, extension 2^{Ω(n)}) — le théorème élimine une
   représentation, pas une route vers NP.
3. **Solveurs modernes à la frontière** : PR/SDCL/DRAT à extension
   (HKB17 : PHP et Tseitin en temps polynomial) — la frontière de
   l'élimination passe à l'intérieur des solveurs actuels ; le noyau
   résolution seul est éliminé (CaDiCaL 1.9.5 : ×6,55 par pigeon
   jusqu'à 14,4 M conflits — pas de raisonnement cardinal).
4. « Formulations étendues rejetée le 2026-09-08 » : [NON TROUVÉ dans
   le dépôt] ; « Haken 0 » inexact pour bib (présent dans
