## Ce qui a été fait

1. **Réplication vérifiante des deux scripts utilisateur** (leurs
   identités : invariance de jauge, annulation des excitations simples
   à la jauge BP, boucles généralisées, 625 termes, min-support 10) —
   CONFORME point par point ; et un fait meilleur que leur en-tête :
   S(alignée-clause) = 10 < 2^m = 32 annoncé.
2. **L'évaluateur hybride construit** (`checks/hol002_hybride.py`) :
   dictionnaire de jauges-îles par arête + recuit budgété minimisant
   le support S, évaluation par somme restreinte, chaque somme
   RE-VÉRIFIÉE contre Z exact (assertion, 17/17).
3. **La campagne** : contrôles (instance utilisateur ; arbre + 0/1/2
   cordes — l'île BP y gagne : S = 1/5/50) + famille dure 3-régulière
   bipartie m = n, n = 4..8 (E = 12..24), 3 graines (1 à n = 8).
4. **Les deux faits mesurés** : (i) S_min ≈ 0.4-0.6 × #SAT sur toute
   la famille dure — croissance exponentielle (courbe à 5 points,
   ratios ×1.6 → ×1.9) ; (ii) le minimum est SUR une île pure dans
   17/17 instances — le recuit n'a jamais produit un hybride
   strictement meilleur (0/13 sur la famille dure).
5. Verdict rendu à la piste : l'hybride calcule Z en polynomial
   exactement là où une île pure le faisait déjà ; l'orbite unifie
   sans étendre. Observation de lecture consignée (non prouvée) : la
   section alignée-clause ~ inclusion-exclusion sur les clauses.
