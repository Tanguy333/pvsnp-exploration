## Question

T-F006 prouve `W_L1 = DNF_min` pour IP. Îlot ou continent ?

## Réponse : une classe d'égalité **rare, décroissante, et structurée**

| n | W < DNF_min | W = DNF_min | W > DNF_min |
|---|---|---|---|
| 3 (254 f) | 1 (0.4 %) | **30 (11.8 %)** | 223 (87.8 %) |
| 4 (65 534 f) | 93 (0.1 %) | **575 (0.9 %)** | 64 866 (99.0 %) |

1. **Le générique est W > DNF_min** (99 % à n=4) : pour presque toutes les
   fonctions, la weight PTF réelle excède la taille du DNF minimal.
   L'égalité (la classe d'IP) est rare : 11.8 % → 0.9 % — fraction
   décroissante, comme la classe d'essentialité du Tour 19 (79.5 % → 36.4 %)
   mais bien plus vite.
2. **L'égalité n'implique PAS l'essentialité** : à n=3, les 30 cas d'égalité
   sont tous essentiels ; à n=4, **78 des 575** ne le sont pas (ex. :
   fmask 27370 — 5 primes, DNF_min = 4, W = 4). Les deux classes se
   chevauchent sans inclusion.
3. **W < DNF_min : ultra-rare et expliqué par le terme constant.** L'unique
   cas à n=3 est `f = ¬AND₃` : DNF_min = 3 (¬x∨¬y∨¬z), mais
   `p = 1 − xyz` a W = 2 — le polynôme utilise la constante, ce qu'aucun
   DNF ne peut faire. Les 93 cas de n=4 ont le même parfum (profils
   dominants : compléments de petites structures, ex. ones=15 = ¬minterme).
4. **La weight réelle peut être fractionnaire** : fmask 6015 a
   `W_ℝ = 4.5` (avec DNF_min = 6) — l'optimum LP n'est pas toujours
   entier, donc la mesure sur ℝ est strictement plus fine que sur ℤ
   (W_ℤ ≥ 5 là). À noter pour la note : T-F006 vaut sur ℝ, c'est la bonne
   généralité.

## Position d'IP dans la carte

IP_4 ∈ classe d'égalité ∩ classe d'essentialité (575 ∩ 23 862 = 497
fonctions à n=4). La classe d'égalité par |f⁻¹(1)| s'étale sur tous les
niveaux (pic à 9) — pas un artefact de taille.
