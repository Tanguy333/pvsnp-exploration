## Théorème T-F006 (clôture complète d'O-F002)

> **Pour tout k ≥ 1, la weight L1 minimale d'une représentation à seuil de
> `IP_{2k}` par polynôme RÉEL (base monômiale 0/1) est exactement**
>
> `W_L1(IP_{2k}) = (3^k − 1)/2 = DNF_min(IP_{2k})`.

## Preuve

**Borne supérieure** (T-F004) : le polynôme multilinéaire exact
`p* = (1 − Π(1−2x_iy_i))/2` a L1 = (3^k−1)/2. ∎

**Borne inférieure — le certificat diagonal** (nouveau). Définir la mesure
signée supportée par les entrées **diagonales** z = (x, x) :

```
w(x,x) = (−1)^{|x|+1} · 2^{k−|x|}   si |x| ≥ 1
w(0,0) = −(2^k − 2)
```

(i) *Signes corrects* : w > 0 ssi |x| impair ssi IP(x,x) = 1. ✓

(ii) *Moments de sous-cube tous égaux à ±1*. Pour un monôme S touchant
s = p+q ≥ 1 paires (r = k−s libres) : sur la diagonale, z ⊇ S ⟺ x couvre
les s paires touchées, donc

```
μ(S) = Σ_{j=0}^{r} C(r,j) · (−1)^{s+j+1} 2^{k−s−j}
     = (−1)^{s+1} 2^{k−s−r} (2−1)^r = (−1)^{s+1}        [car k−s−r = 0]
```

Et `μ(∅) = −(2^k−2) + Σ_{j≥1} C(k,j)(−1)^{j+1}2^{k−j} = −(2^k−2) + (2^k−1) = 1`.

(iii) *Valeur* : `Σ_{a impair} C(k,a) 2^{k−a} = ((2+1)^k − (2−1)^k)/2 = (3^k−1)/2`.

(iv) *Dualité faible*. Soit p réel avec p ≥ 1 sur IP⁻¹(1), p ≤ 0 sur
IP⁻¹(0). Alors `w_z·p(z) ≥ w_z` sur les 1-entrées (w ≥ 0, p ≥ 1) et
`w_z·p(z) ≥ 0` sur les 0-entrées (w ≤ 0, p ≤ 0), d'où

```
(3^k−1)/2 = Σ_{IP=1} w_z ≤ Σ_z w_z p(z) = Σ_S c_S μ(S) ≤ Σ_S |c_S| = W.
```
∎

**Égalité avec DNF_min** : Tours 17-18 (+ vérification directe n=1..5,
F-005b). ∎

## Vérification exécutable de la preuve

- **Niveau orbites, arithmétique exacte (Fractions), k = 1..14** : tous les
  moments = (−1)^{s+1}, μ(∅) = 1, signes des poids corrects, valeur =
  (3^k−1)/2. ✅ 14/14.
- **Force brute intégrale, k = 1..4** : chaque monôme S ⊆ [2k] (jusqu'à 256)
  × chaque entrée (jusqu'à 256), sans réduction par orbites. ✅ 4/4.

## Comment la forme close a été trouvée

Le LP réduit aux orbites (variables u/v(a,b,c), O(k²)) avec canonisation par
masse minimale a donné à k = 2, 3, 4 des sommets **parfaitement propres,
tous supportés sur b = 0** (la diagonale) : u(1,0,k−1) = 2^{k−1},
u(3,0,k−3) = 2^{k−3}, v(2,0,k−2) = 2^{k−2}, …, v(0,0,k) = 2^k − 2.
(À k ≥ 5 le solveur retournait des sommets dégénérés illisibles — la forme
close vient des petits k, la preuve vaut pour tous.)

**Esthétique** : le certificat vit sur la diagonale x = y, où
`IP(x,x) = |x| mod 2 = PARITY(x)` — la borne inférieure d'IP se réduit à
une mesure de type parité sur le sous-cube diagonal.
