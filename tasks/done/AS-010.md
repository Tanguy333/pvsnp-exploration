# AS-010 — THÉORÈME (inconditionnel) : MAJ_{2d−1} a une représentation torique exacte de degré d ⟺ d = 2^k

- **Type** : V (théorème + preuve complète, chaque maillon vérifié par calcul)
- **Exécutée le** : 2026-07-02
- **Vérifications** : 4 maillons algébriques (identité alternée N < 40 ;
  version mod 2 ; Lucas d < 130 ; critère kernel réel d = 2..25) + le
  13/13 d'AS-009 (jusqu'à d = 32).

## Théorème

Soit d ≥ 2, n = 2d−1, f = MAJ_n (seuil w = d). Alors :

> **Il existe Z : {0,1}ⁿ → Z et un polynôme multilinéaire réel p de degré
> ≤ d avec p = Z + MAJ_n/2 exactement (D_full = 0) SI ET SEULEMENT SI d
> est une puissance de 2.**
> De plus, si d n'est pas une puissance de 2 :
> **D_full(2d−1, d) ≥ 1/2^{d+3}** (borne quantitative inconditionnelle).

Les deux directions sont inconditionnelles — AUCUN recours à l'hypothèse
symétrique.

## Preuve

**(⟸) d = 2^k ⟹ représentation exacte (symétrique).** En poids-espace,
le réseau dual est L_{d,n} = {γ ∈ Z^{n+1} : (1−x)^{d+1} | γ(x)} (les
moments binomiaux C(k,i), i ≤ d, engendrent les polynômes de degré ≤ d ;
V-007). Base stencil : γ⁽ⁱ⁾ = coefficients de x^i(1−x)^{d+1},
i = 0..d−2. Le critère exact (AS-009, forme définie positive sur le
quotient + saturation) : D_sym = 0 ⟺ ⟨γ⁽ⁱ⁾, f⟩ pair pour tout i. Calcul :

  ⟨γ⁽ⁱ⁾, f⟩ = Σ_{j ≥ d−i} (−1)^j C(d+1, j) = ±C(d, d−i−1) = ±C(d, i+1)

(identité de somme partielle alternée, vérifiée pour N < 40). Donc
D_sym = 0 ⟺ C(d, r) pair pour tout r = 1..d−1 ⟺ (Lucas) d = 2^k.
Un témoin symétrique étant un témoin : D_full = 0. ∎

**(⟹) d ≠ 2^k ⟹ aucune représentation exacte, même asymétrique.**
Si d n'est pas une puissance de 2, Lucas donne r ∈ {1..d−1} avec C(d, r)
IMPAIR. Prendre s = d−r−1 ∈ {0..d−2} (≤ nombre de coordonnées fixées :
n−(d+1) = d−2 ✓) et le dual de sous-cube η : motif (−1)^{|y|} sur un
(d+1)-sous-cube dont les coordonnées fixées portent s uns. Alors
η ⊥ V_d (tout monôme de degré ≤ d manque une coordonnée libre — la somme
alternée s'annule), η entier, et

  ⟨η, f⟩ = Σ_j (−1)^j C(d+1, j)·[s+j ≥ d] = ±C(d, d−s−1) = ±C(d, r) impair.

Donc pour tout Z entier : ⟨η, Z + f/2⟩ ∈ Z + ½, d'où Z + f/2 ∉ V_d, et
quantitativement dist ≥ (1/2)/‖η‖₂ = 1/2^{(d+3)/2}, soit D ≥ 1/2^{d+3}. ∎

## Portée

1. **Explique le Théorème 1.4 de KV** : leur condition « d = 2^t » (bornes
   sup surprenantes, erreur 1/2^{Ω(n)} à n = 2d+1) n'est pas un artefact
   de construction — c'est la loi de parité binaire. Notre théorème donne
   la version exacte (erreur NULLE, n = 2d−1) et la réciproque
   (impossibilité stricte hors puissances de 2), absentes de leur papier
   (§4 vérifié : approximatif seulement, pas de sens « seulement »).
2. **Généralisation immédiate disponible** (AS-011) : le critère de parité
   ⟨γ⁽ⁱ⁾, THR_w⟩ = ±C(d, w−i−1) caractérise le lieu D_sym = 0 de TOUTE
   cellule (n, d, w) en O(n²) — la carte complète des représentations
   exactes est à portée de main ; et les duaux de sous-cube donnent
   l'impossibilité inconditionnelle sur une grande partie du complément.
3. Pour la Conjecture 13 : confirme que la diagonale est structurée par
   l'arithmétique binaire — le « bombage » hors puissances de 2 est borné
   inférieurement par 1/2^{d+3} (explicite), les Mersenne restent le cas
   minimal (D = 1/8 mesuré, motif de témoins à élucider).
