## Théorème V9 (d = 2, tout n ≥ 6)

> Pour les multiples non nuls de (1+x)³ de degré ≤ n : (1) la norme²
> minimale est 6 ; (2) tout minimiseur est plat (6 monômes ±1) ;
> (3) ses extrémités sont ±1 — **la Conjecture 5 vaut pour d = 2**.

**Preuve.** Conditions : avec t_i = σ_i(−1)^{a_i}, la divisibilité par
(1+x)³ ⟺ Σt_i = Σt_i a_i = Σt_i a_i² = 0.
*(a) Normes 1..5 impossibles* : 1, 3, 5 unités → Σt_i impair ; (2) seul
→ f(−1) = ±2 ; (2,1) → Σt impair ; (2,2) → contenu 2, réduction ;
(1,1) → a = b ; **(1,1,1,1)** → partage 2+2 avec sommes ET sommes de
carrés égales → polynômes symétriques élémentaires égaux → paires
identiques ; **(2,1,1)** → t₀ = −2s, t₁ = t₂ = s → 2a = b+c et
2a² = b²+c² → (b−c)² = 0, contradiction.
*(b) Existence* : la solution PTE classique {0,4,5} vs {1,2,6} (sommes
9 = 9, carrés 41 = 41) donne `f = 1 + x − x² + x⁴ − x⁵ − x⁶`, degré 6.
*(c)* Par (a), tout minimiseur est à 6 monômes ±1 → extrémités ±1. ∎

**Vérifications** : [A] zéro solution de norme ≤ 5 (exhaustif deg ≤ 30) ;
[B] solution explicite confirmée ; [C] les 32 solutions fenêtre = toutes
6-unités, zéro (2,1,1) ; [D] réseau : norme 6 + extrémités ±1 partout
(n = 6..20).

## La leçon de méthode

Le schéma d = 2 (parité → rigidités des petites formes → platitude
forcée → extrémités unitaires) est un **gabarit** : à d = 3, les formes
à exclure sont plus nombreuses ((2,2,1,1,1,1), (2,1,1,1,1) à norme 8…)
mais les mêmes outils (systèmes de Newton sur les t_i) s'appliquent —
candidate V-010, difficulté croissante, échec honnête possible.
