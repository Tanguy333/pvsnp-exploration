## Les trois formes closes (vérifiées en exact sur grilles)

> **Forme maîtresse** : ‖(1−x)^D(1+x)^j‖² = **P_j(D) = (2D)!(2j)!/(D!·j!·(D+j)!)**
> (contient V24 : j=1 → 2·Catalan(D) ; et toute l'échelle V25).
>
> Sur le cercle, |Φ₃|² = (1+u)² et |2Φ₃+x|² = (3+2u)² (carrés
> parfaits, u = 2cosθ) ⟹ par linéarité :
> **N_phi = P_{a+2} − 2P_{a+1} + P_a** ; **N_cœur = 4P_{a+2} − 4P_{a+1} + P_a**.

## Théorème (loi des fenêtres)

1. **Entrée linéaire** : N_cœur < N_phi ⟺ 3P_{a+2} < 2P_{a+1} ⟺
   **D ≥ 5a + 8** (une ligne, via P_{j+1}/P_j = 2(2j+1)/(D+j+1)).
2. **Fenêtre finie** : N_cœur < N_pur ⟺ Q_a(D) > 0 avec
   Q_a(D) = −(D+a+1)(D+a+2) + 8(2a+1)(D+a+2) − 12(2a+1)(2a+3),
   quadratique en D de tête −1 ⟹ intervalle FINI exact :
   a=3 : [17,30] ; a=4 : [19,42] ; a=5 : [22,53] ; a=6 : [25,64].
3. **Fenêtre stricte** (bat les deux) = intersection :
   a=3 → **D ∈ [23, 30] = la marche observée d ∈ [22, 29], à l'entier
   près, sortie comprise** (V-030) ; naissance de la bande d = 17
   (D = 18) ∈ [17, 30] ✓.

## Portée

- Dans la **famille produit** {pur, phi, cœur}, le bord de bande est
  entièrement régi par des formes closes binomiales : la théorie
  V-021→V-030 (rupture, escalier, fenêtres, sorties) est désormais

- Les fenêtres successives se chevauchent et s'étendent (sorties 30,
  42, 53, 64, ~11a) : leur union couvre tout D ≥ 17 — pour chaque
  profondeur, un habit de cœur bat la famille produit à tête 1.
