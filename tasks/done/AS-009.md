## 1. Contexte (pourquoi la diagonale)

La récursion de padding (AS-004/008) transporte les bornes en n à perte
polynomiale — toute la Conjecture 13 se concentre donc sur la base
diagonale n₀ ≈ 2d. AS-009 = l'étape MESURER de la boucle
mesurer → deviner la loi exacte → prouver par algèbre vérifiable
(le mode opératoire qui a produit P_j(D), V11, le lemme de padding).

## 2. Mesures (poids-espace exact ; † = cap, borne sup)

## 3. LA LOI (et son test à 13/13)

> **Candidat-théorème (lieu d'annulation).** D(2d−1, d) = 0 — i.e.
> MAJ_{2d−1} admet une représentation torique EXACTE de degré d —
> **si et seulement si d est une puissance de 2.**

Critère décisif trouvé : D = 0 ⟺ **Cf ≡ 0 (mod 2)** coordonnée par
coordonnée (la forme est définie positive sur le quotient ; test exact
en O(n²), sans CVP). Vérifié pour d = 2..32 (13 valeurs testées dont
d = 16, 32 hors de tout calcul antérieur) : **13/13 conforme**.

**Chemin de preuve (algèbre vérifiable — AS-010)** : les parités de Cf
sont des sommes de binomiales mod 2 ⟹ théorème de **Lucas/Kummer**
(chiffres binaires) — exactement la structure observée. Une preuve
combinatoire vérifiable par sympy est plausible, comme pour les lois
base-3 de F-011.

## 4. Prédiction 2 (Mersenne : D(2d+1, d) = 1/8 pour d = 2^k − 1) : NON TESTÉE

À d = 15 (dim 16), Babai + descente rend une borne sup énorme (~3,3·10⁵)
et l'énumération cappe — l'instrument local échoue, la prédiction n'est
NI confirmée NI réfutée. Chemin correct (AS-010) : extraire les témoins
exacts de d = 1, 3, 7, identifier le motif (vraisemblablement récursif/
auto-similaire au doublement), construire le candidat d = 15 et VÉRIFIER
par évaluation exacte de la forme (instantané, sans recherche).

## 5. Antériorité et connexion KV

Le sens ⟸ (d = 2^k ⟹ représentation exacte/quasi-exacte) est ADJACENT
au Théorème 1.4 de KV (d = 2^t, n = 2d+1, erreur 1/2^{Ω(n)} — leurs
« surprising upper bounds », §4) — leur construction pourrait donner
notre D = 0 à n = 2d−1 : **à vérifier sur leur §4 avant toute
revendication du sens ⟸**. Le sens ⟹ (annulation SEULEMENT aux
puissances de 2) et le critère de parité exact semblent neufs.

## 6. Conséquence pour la Conjecture 13 (cadrage affûté)

À d Mersenne, la base diagonale est minuscule (D = 1/8, soit
q ~ 2^{−n}/8) : la récursion seule ne peut PAS donner la conjecture —
tout le poids repose sur le « bombage » hors-centre (l'excès
d'intrication d'AS-006), qui doit fournir un facteur ~2^{2d}/poly entre
n₀ = 2d et n ~ d². La conjecture est maintenant posée comme une question
de TAUX D'ACCUMULATION de l'excès — mesurable, et peut-être analysable
via Krawtchouk + la structure binaire.
