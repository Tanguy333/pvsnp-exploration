## 1. Deux lemmes prouvés (l'algèbre vérifiable annoncée)

**Lemme de structure.** Les vecteurs admissibles a (a_k = C(2d+1,k)q(k),
q polynôme de degré ≤ d) sont exactement les A(x) = (1+x)^{d+1}R(x),
deg R ≤ d. *Preuve* : la base q = C(k,j) donne
A_j = C(n,j)x^j(1+x)^{n−j} et n−d = d+1 ; {x^j(1+x)^{d−j}} engendre
tous les polynômes de degré ≤ d. ∎

**Lemme de parité.** Pour A = x^s(1+x)^{d+1}B(x) :
Σ_{k>d}(−1)^k a_k ≡ Σ_m b_m·C(d, s+m) (mod 2). *Preuve* : linéarité en
B ; pour B = x^m, l'identité des sommes partielles alternées
Σ_{j=t}^{M}(−1)^jC(M,j) = (−1)^tC(M−1, t−1) avec M = d+1, t = d+1−s−m
donne ±C(d, s+m). ∎ (Vérifié : 100/100 cas aléatoires.)

**Corollaire (Lucas).** Pour B = 1 : certificat impair ⟺ C(d,s) impair
⟺ s est un sous-masque binaire de d. L'intégralité est triviale
(coefficients binomiaux). Il ne manque que la NORME.

## 2. La loi mesurée (d = 1..32 exhaustif + d lointains)

Le minimiseur structuré est presque partout :
> **s* = d − 2^⌊log₂ d⌋ (la queue binaire de d), B = (1−x)²**

— la queue est toujours un sous-masque (bits disjoints de la tête), et
(1−x)² amortit le col central. Normes : excellentes quand s* ~ d/2
(moitié HAUTE de chaque bloc dyadique : ν jusqu'à 0,039 à d=29, soit
b_29 ≥ 6,36) ; dégradation exponentielle quand d approche 2^t par
au-dessus (queue → 0) : ν = 107 (d=16), 2,7·10⁹ (d=64), ~10⁴⁰ (d=256).

**Explication entropique** (argument, pas théorème) : par entropie
binaire, N(d, αd) a un exposant exponentiel nul ssi α = 1/2 — la parité
force s parmi les sous-masques de d, et la distance du meilleur
sous-masque à d/2 gouverne tout. Miroir exact de la loi des résidus
d'AS-023 (deg q = distance au prochain Mersenne) : toute la théorie de
la diagonale est structurée par blocs dyadiques.

## 3. Bornes obtenues (certificats explicites, évaluation pure)

Dans la moitié haute des blocs : b_d ≥ 0,2..6,4 pour
d ∈ {5,6,10..15, 20..31, 48, 96, ...} — sans aucune énumération, par
la famille close. Zone basse (d = 2^t et juste au-dessus) : la famille
courte échoue, MAIS AS-024 a mesuré des certificats bornés à d = 8, 16
(μ ≈ 2,2, 2,1) — de type « quasi-plat » : A = (1−x²)(1+x)^d·S, S
palindromique à petits coefficients ≈ série inverse tronquée de
1/((1−x)(1+x)^{d+1}) (structure Padé). Ils existent ; leur forme close
n'est pas encore écrite.

(Artefact consigné : d = 320/400 en phase 2 ont raté leur sous-masque
optimal — hors fenêtre de scan s = centre±40 ; sans conséquence, la
loi de la queue les couvre : s*(320) = 64, s*(400) = 144.)

## 4. État du programme « b_d ≥ constante uniforme »

- Prouvé : structure + parité/Lucas + intégralité (§1) ; il ne manque
  que le lemme de norme, en DEUX morceaux :
  (a) N(d, s) = O(1) pour |s − d/2| = O(1) — élémentaire (ratios de
  termes), à rédiger ; couvre tout d à sous-masque central ;

  ‖(1−x²)(1+x)^d S_d‖ borné et parité impaire.
- Si (a)+(b) : **b_d ≥ c > 0 pour tout d** ⟹ AS-022 avec perte ~2^d —
  l'étage base de la Conjecture 13 clos.
